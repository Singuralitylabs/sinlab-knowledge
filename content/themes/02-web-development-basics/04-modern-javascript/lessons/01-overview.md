# モダンJavaScript

## はじめに

JavaScript は 1995 年の誕生以来、少しずつ進化してきましたが、**2015 年に公開された ES2015（通称 ES6）** で大きく生まれ変わりました。それ以降、毎年新しい仕様が追加され続けており、これらをまとめて「モダンJavaScript（ES6+）」と呼びます。

ES6 より前の JavaScript には、次のような書きにくさ・分かりにくさがありました。

- 変数宣言は `var` のみで、スコープの挙動が直感に反する
- 関数定義が冗長で、`this` の扱いがややこしい
- 文字列の組み立てが `+` の連結だらけになる
- オブジェクトや配列から値を取り出すコードが長くなる

モダンJavaScript はこうした課題を解消し、**短く・安全に・読みやすく** コードを書けるようにします。現在の業務開発・React や Vue などのフレームワーク・生成AIが出力するコードも、ほぼすべてがこのモダンな書き方を前提にしています。今のうちに身につけておくと、あらゆる教材やサンプルコードがすらすら読めるようになります。

> [!NOTE]
> このモジュールは「JavaScript（基礎）」モジュールを学んだ後を想定しています。基礎モジュールで触れた `let` / `const` の入門的な使い方には深入りせず、**スコープの仕組みやモダンな使い分け**といった一歩踏み込んだ内容を扱います。

ここでは以下の 8 つのトピックを順に紹介します。各トピックの概要をつかんだら、続く各レッスンで詳しく学んでいきましょう。

---

## let / const とブロックスコープ

`var` に代わる変数宣言として登場したのが `let` と `const` です。`let` は再代入できる変数、`const` は再代入できない定数を宣言します。どちらも `{ }` の範囲（ブロック）だけで有効な**ブロックスコープ**を持つため、`var` で起こりがちだった意図しない変数の上書きを防げます。「迷ったら `const`、再代入が必要なときだけ `let`」が基本方針です。

---

## アロー関数

アロー関数は `=>` を使った関数の書き方で、従来の `function` 式より短く書けます。さらに、アロー関数は自分自身の `this` を持たず、外側のスコープの `this` をそのまま引き継ぐため、コールバック関数の中で `this` がずれてしまう問題を自然に回避できます。配列メソッドのコールバックなど、短い関数を渡す場面で特に活躍します。

---

## テンプレートリテラル

バッククォート（`` ` ``）で文字列を囲むテンプレートリテラルを使うと、`${ }` の中に変数や式を直接埋め込めます。`+` で文字列を連結する必要がなくなり、改行を含む複数行の文字列もそのまま書けます。動的なメッセージや HTML の組み立てが一気に読みやすくなります。

---

## 分割代入

分割代入（Destructuring）は、配列やオブジェクトの中身を一度に取り出して変数に代入する構文です。`const { name, age } = user;` のように書くだけで、必要なプロパティをまとめて受け取れます。関数の引数で受け取る、デフォルト値を設定する、といった応用も効き、コードの記述量を大きく減らせます。

---

## スプレッド構文とレスト構文

`...` という同じ記号が、文脈によって 2 つの役割を持ちます。**スプレッド構文**は配列やオブジェクトを展開してコピー・結合するのに使い、**レスト構文**は複数の値を 1 つの配列やオブジェクトにまとめるのに使います。元のデータを壊さずに新しいデータを作る「イミュータブル（非破壊的）」なコードを書くための必須テクニックです。

---

## ES Modules (import / export)

ES Modules は、JavaScript のコードを複数のファイルに分割し、`export` で公開・`import` で取り込む仕組みです。機能ごとにファイルを分けて整理でき、再利用もしやすくなります。現在のフロントエンド開発やビルドツールは、この ES Modules を標準として動いています。

---

## クラス構文

`class` キーワードを使うと、データとそれを操作するメソッドをひとまとめにした「クラス」を、わかりやすい構文で定義できます。`constructor` での初期化や `extends` による継承もサポートされ、オブジェクト指向のコードを直感的に書けます。

---

## オプショナルチェイニングとNull合体演算子

`?.`（オプショナルチェイニング）を使うと、途中のプロパティが存在しなくてもエラーにならず、安全にネストしたプロパティへアクセスできます。`??`（Null合体演算子）は、値が `null` または `undefined` のときだけ既定値を使う演算子です。API から受け取ったデータなど「あるかどうか分からない値」を安全に扱うために役立ちます。

---

## まとめ

- **ES6 (ES2015)** 以降のモダンJavaScript は、コードを短く・安全に・読みやすくするための構文を多数提供します。
- 変数宣言は `let` / `const` を使い、`var` は使わないのが現在の基本です。
- アロー関数・テンプレートリテラル・分割代入・スプレッド/レスト構文は、日々のコードを簡潔にする定番の道具です。
- ES Modules でファイルを分割し、クラスでオブジェクト指向を表現できます。
- オプショナルチェイニングと Null 合体演算子は、不確実なデータを安全に扱う助けになります。
