# 関数

## 解説

**関数**は、一連の処理をひとまとめにして名前を付けたものです。一度作っておけば、何度でも呼び出して使えます。同じ処理を繰り返し書かずに済み、プログラムを整理できます。

---

## 関数の宣言

`function` キーワードで関数を定義します。

```js
function greet() {
  console.log("こんにちは");
}

greet(); // 関数を呼び出す → こんにちは
greet(); // 何度でも呼べる → こんにちは
```

- `function 関数名() { ... }` で定義する。
- `関数名()` と書くと、中の処理が実行される（これを「呼び出す」と言う）。

---

## 引数と戻り値

関数には**引数**（値を渡す入口）と**戻り値**（結果を返す出口）を持たせられます。

```js
function add(a, b) {
  return a + b; // 計算結果を返す
}

const result = add(3, 5);
console.log(result); // 8
```

- `a`, `b` が**引数**。呼び出すときに渡した値（`3`, `5`）が入る。
- `return` で**戻り値**を返す。`return` した値が `add(3, 5)` の結果になる。

> [!NOTE]
> `return` を書かない関数は、自動的に `undefined` を返します。値を呼び出し元に渡したいときは `return` が必要です。

---

## デフォルト引数

引数が渡されなかったときの初期値を指定できます。

```js
function greet(name = "ゲスト") {
  console.log(`こんにちは、${name}さん`);
}

greet("田中"); // こんにちは、田中さん
greet(); // こんにちは、ゲストさん（省略時はデフォルト値）
```

---

## 関数式

関数を変数に代入する書き方もあります。これを**関数式**と呼びます。

```js
const multiply = function (a, b) {
  return a * b;
};

console.log(multiply(4, 5)); // 20
```

「関数宣言」と「関数式」はどちらも関数を作る方法です。まずは `function 関数名() {}` の宣言形式に慣れておけば十分です。

---

## スコープ（変数の有効範囲）

関数の中で `let` / `const` で宣言した変数は、その関数の中でしか使えません。これを**スコープ**と呼びます。

```js
function calc() {
  const local = 10; // この関数の中だけで有効
  console.log(local); // 10
}

calc();
console.log(local); // エラー: 関数の外からは見えない
```

**ポイント**

- 変数のスコープを限定することで、別の場所での予期しない書き換えを防げます。
- 関数の外で宣言した変数は、関数の中からも参照できます（逆は不可）。

---

## アロー関数（発展）

`=>`（矢印）を使った、より短い関数の書き方に**アロー関数**があります。モダンな JavaScript で頻繁に使われますが、`this` の扱いなど通常の関数と異なる性質もあるため、本コースでは「モダンJavaScript」モジュールでまとめて解説します。

詳しくは [アロー関数](/themes/02-web-development-basics/04-modern-javascript/arrow-functions) を参照してください。

---

## まとめ

- 関数は処理をまとめて名前を付けたもの。`function 名前() {}` で定義し、`名前()` で呼び出す。
- 引数で値を受け取り、`return` で戻り値を返す。デフォルト引数で省略時の値を指定できる。
- 関数内で宣言した変数は、その関数のスコープ内でのみ有効。
- より短い「アロー関数」という書き方は「モダンJavaScript」モジュールで詳しく学ぶ。
