# タイポグラフィと色

## 解説

文字（タイポグラフィ）と色は、ページの**読みやすさ**と**印象**を大きく左右する基礎要素です。レイアウトが整っていても、文字が読みにくかったり配色が見づらかったりすると、使いにくいページになってしまいます。ここでは、文字まわりの基本プロパティと、色の指定方法を整理します。

## フォントの指定

`font-family` で書体を指定します。複数指定しておくと、先頭から順に「使えるものがあれば使う」という挙動になります。最後には総称ファミリ（`sans-serif` など）を置くのが定番です。

```css
body {
  font-family: "Helvetica Neue", Arial, sans-serif;
}
```

最近では、端末標準のフォントを使う `system-ui` もよく用いられます。読み込みが速く、各 OS で自然な見た目になります。

```css
body {
  font-family: system-ui, sans-serif;
}
```

文字の大きさや太さは次のように指定します。

```css
.title {
  font-size: 1.5rem;     /* 大きさ */
  font-weight: bold;     /* 太さ（normal / bold / 100〜900） */
}

.note {
  font-style: italic;    /* 斜体 */
}
```

---

## line-height（行間）

`line-height`（行の高さ）は、行と行の間隔を決める重要なプロパティです。とくに本文では、適切な行間が読みやすさを大きく高めます。

```css
p {
  line-height: 1.7;  /* 単位なしの数値が推奨 */
}
```

**ポイント**
- 単位なしの数値（例：`1.7`）にすると、「文字サイズの 1.7 倍」という相対指定になり、文字サイズが変わっても比率が保たれます。
- 本文は `1.5〜1.8` 程度が読みやすい目安です。見出しは `1.2〜1.3` 程度に詰めることが多いです。

---

## 文字まわりの単位

文字サイズには `px` のほか、相対単位の `rem` / `em` がよく使われます。

```css
html { font-size: 16px; }   /* ルートの基準サイズ */

.box {
  font-size: 1.5rem;  /* ルート基準：16 × 1.5 = 24px */
}

.child {
  font-size: 1.25em;  /* 親要素の文字サイズ基準 */
}
```

| 単位 | 基準 | 特徴 |
|------|------|------|
| `px` | 固定 | わかりやすいが拡大に追従しない |
| `rem` | ルート（`html`）の文字サイズ | サイト全体で一貫したスケール |
| `em` | 親要素の文字サイズ | 入れ子で値が累積する点に注意 |

> [!TIP]
> 文字サイズは `rem` を基本にすると、サイト全体のサイズ感を `html` の `font-size` だけで一括調整できます。アクセシビリティ（ユーザーのブラウザ設定で文字を大きくする）にも対応しやすくなります。

## 色の指定：color と background

文字色は `color`、背景色は `background`（または `background-color`）で指定します。

```css
.card {
  color: #1f2937;        /* 文字色 */
  background: #f9fafb;   /* 背景色 */
}
```

---

## 色の表し方（hex / rgb / hsl）

CSS では色をいくつかの方法で表現できます。どれも同じ色を指せます。

### 16進数（hex）

`#` に続けて RGB を16進数で表します。最も広く使われる形式です。

```css
.a { color: #ff0000; }   /* 赤 */
.b { color: #00ff00; }   /* 緑 */
.c { color: #1d4ed8; }   /* 青系 */
.d { color: #333; }      /* #333333 の省略形（3桁） */
```

### rgb / rgba

赤・緑・青を 0〜255 で指定します。`rgb()` に4つ目の値（不透明度 0〜1）を加えると半透明にできます。

```css
.a { color: rgb(255, 0, 0); }              /* 赤 */
.b { color: rgb(29, 78, 216); }            /* 青系 */
.c { background: rgb(0, 0, 0, 0.5); }      /* 黒の半透明（50%） */
```

### hsl / hsla

色相（Hue 0〜360）・彩度（Saturation %）・明度（Lightness %）で指定します。「同じ色味で明るさだけ変える」といった調整が直感的にできます。

```css
.a { color: hsl(0, 100%, 50%); }    /* 赤 */
.b { color: hsl(220, 70%, 50%); }   /* 青系 */
.c { color: hsl(220, 70%, 70%); }   /* 同じ色味で明るめ */
```

| 形式 | 例 | 特徴 |
|------|------|------|
| hex | `#1d4ed8` | 簡潔で最も一般的 |
| rgb / rgba | `rgb(29,78,216)` | 透明度を扱いやすい |
| hsl / hsla | `hsl(220,70%,50%)` | 色味・明るさの調整が直感的 |

---

## 実用例

```css
body {
  font-family: system-ui, sans-serif;
  font-size: 1rem;
  line-height: 1.7;
  color: #1f2937;        /* 濃いグレーの文字（真っ黒より柔らかい） */
  background: #ffffff;
}

h1 {
  font-size: 2rem;
  line-height: 1.25;
  color: #111827;
}

a {
  color: hsl(220, 70%, 45%);
}
```

**ポイント**
- 本文の文字色を真っ黒（`#000`）ではなく濃いグレー（`#1f2937` など）にすると、コントラストが和らぎ読みやすくなります。
- 文字色と背景色のコントラストが弱いと読みにくくなります。アクセシビリティの観点からも、十分な明暗差を確保しましょう。

---

## まとめ

- `font-family` は複数指定し、末尾に `sans-serif` などの総称ファミリを置きます。`system-ui` も実用的です。
- `line-height` は**単位なしの数値**で指定し、本文は `1.5〜1.8` が読みやすい目安です。
- 文字サイズは `rem` を基本にすると、サイト全体のスケールを一括調整でき、アクセシビリティにも対応しやすくなります。
- 色は **hex / rgb(a) / hsl(a)** で指定でき、透明度なら rgba、色味の調整なら hsl が扱いやすいです。
