# セレクタ

## 解説

**セレクタ**は「どの要素にスタイルを適用するか」を指定する部分です。狙った要素を正確に選べるようになることが、CSS を使いこなす第一歩です。ここでは基本のセレクタから、要素同士の関係を使った指定、そして競合時の優先順位を決める**特定性（詳細度）** までを順に見ていきます。

説明には次の HTML を使います。

```html
<div id="main">
  <h1 class="title">見出し</h1>
  <p class="lead">最初の段落です。</p>
  <p>2番目の段落です。</p>
  <a href="https://example.com" target="_blank">外部リンク</a>
  <ul>
    <li>項目1</li>
    <li>項目2</li>
    <li>項目3</li>
  </ul>
</div>
```

---

## 基本のセレクタ

```css
/* 要素セレクタ：そのタグすべてに適用 */
p {
  color: #333;
}

/* クラスセレクタ：class="title" の要素に適用（先頭にドット） */
.title {
  font-size: 28px;
}

/* id セレクタ：id="main" の要素に適用（先頭にシャープ） */
#main {
  max-width: 800px;
}

/* 全称セレクタ：すべての要素に適用 */
* {
  margin: 0;
}
```

**ポイント**
- クラスは複数の要素で使い回せます。スタイルの基本はクラスで指定するのが定番です。
- id はページ内で1回しか使えません。スタイル目的では多用せず、クラスを優先しましょう。

## 属性セレクタ

要素が持つ属性や、その値に基づいて選択できます。

```css
/* target 属性を持つ要素 */
a[target] {
  color: #d97706;
}

/* href が "https" で始まるリンク */
a[href^="https"] {
  font-weight: bold;
}

/* href が ".pdf" で終わるリンク */
a[href$=".pdf"] {
  color: #b91c1c;
}
```

| 記法 | 意味 |
|------|------|
| `[属性]` | その属性を持つ |
| `[属性="値"]` | 値が完全一致 |
| `[属性^="値"]` | 値が指定で始まる |
| `[属性$="値"]` | 値が指定で終わる |
| `[属性*="値"]` | 値に指定を含む |

---

## 結合子（要素の関係で選ぶ）

要素同士の位置関係を使って絞り込めます。

```css
/* 子孫結合子（半角スペース）：#main の中のすべての p */
#main p {
  line-height: 1.7;
}

/* 子結合子（>）：#main の直接の子である p のみ */
#main > p {
  margin-bottom: 12px;
}

/* 隣接兄弟結合子（+）：h1 の直後にある p のみ */
h1 + p {
  font-weight: bold;
}

/* 一般兄弟結合子（~）：h1 より後ろにあるすべての p */
h1 ~ p {
  color: #555;
}
```

**ポイント**
- 子孫（スペース）は「中にある」、子（`>`）は「直接の子だけ」。入れ子が深い場合に効き方が変わります。
- 隣接（`+`）は「直後の1つ」、一般兄弟（`~`）は「後ろにある同じ親の兄弟すべて」です。

## 擬似クラス

要素の「状態」や「位置」に応じて適用するのが擬似クラスです（先頭にコロン）。

```css
/* マウスを乗せたとき */
a:hover {
  text-decoration: underline;
}

/* キーボードフォーカス時（アクセシビリティに重要） */
a:focus {
  outline: 2px solid #2563eb;
}

/* リストの奇数番目（ストライプ模様） */
li:nth-child(odd) {
  background: #f3f4f6;
}

/* 最初の子・最後の子 */
li:first-child {
  font-weight: bold;
}
li:last-child {
  border-bottom: none;
}
```

`:nth-child()` は数値や式も使えます。

```css
li:nth-child(2)    { color: red; }   /* 2番目 */
li:nth-child(3n)   { color: blue; }  /* 3の倍数番目 */
```

> [!TIP]
> `:hover` や `:focus` は、リンクやボタンに「反応している」ことをユーザーに伝える大切な指定です。特に `:focus` はキーボード操作の利用者にとって不可欠なので、消さずに残しましょう。

## 特定性（詳細度）

複数のセレクタが同じ要素に当たったとき、どれが勝つかを決めるのが**特定性**です。次の3つの組で数え、左の桁から大きいほうが優先されます。

| 桁 | 数えるもの |
|:--:|------------|
| 1桁目 | id セレクタ（`#main`） |
| 2桁目 | クラス・属性・擬似クラス（`.title`、`[href]`、`:hover`） |
| 3桁目 | 要素・擬似要素（`p`、`li`） |

```css
p              /* (0,0,1) */
.lead          /* (0,1,0) */
#main p        /* (1,0,1) */
#main .lead    /* (1,1,0) */
```

たとえば次のように競合した場合を考えます。

```css
p          { color: black; }  /* (0,0,1) */
.lead      { color: blue;  }  /* (0,1,0) → p より強い */
#main p    { color: red;   }  /* (1,0,1) → さらに強い */
```

`class="lead"` を持つ `#main` 内の `p` には、最も特定性の高い `#main p`（red）が適用されます。同じ特定性どうしなら、**後に書かれたほうが勝ちます**。

**ポイント**
- 特定性は桁ごとの比較です。クラス10個（0,10,0）でも、id 1個（1,0,0）には勝てません。
- 上書きが必要なときは `!important` に頼る前に、特定性をそろえる・セレクタを見直すことを優先しましょう。

---

## まとめ

- 基本は **要素**・**クラス（`.`）**・**id（`#`）**・**属性（`[ ]`）** の4種類。スタイルはクラス中心で書くのが定番です。
- **結合子**（子孫・子 `>`・隣接 `+`・一般兄弟 `~`）で要素の関係から絞り込めます。
- **擬似クラス**（`:hover`、`:focus`、`:nth-child()` など）で状態や位置に応じた指定ができます。
- 競合は **特定性 `(id, クラス等, 要素)`** で決まり、同点なら後勝ちです。
