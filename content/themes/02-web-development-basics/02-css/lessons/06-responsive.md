# レスポンシブ設計

## 解説

**レスポンシブデザイン**とは、PC・タブレット・スマートフォンなど、画面の幅に応じてレイアウトを自動的に切り替える設計手法です。1つの HTML/CSS であらゆる画面サイズに対応できるため、現在の Web 制作では標準的な考え方になっています。

実現の柱は次の4つです。

1. **ビューポート meta タグ**（スマホで正しく表示する前提）
2. **メディアクエリ**（画面幅で CSS を切り替える）
3. **モバイルファースト**（小さい画面を基準に組み立てる）
4. **相対単位**（画面に応じて伸縮するサイズ指定）

---

## ビューポート meta タグ

まず HTML の `<head>` に、次の1行が必要です。これがないと、スマートフォンが PC 用の幅でページを縮小表示してしまい、文字が極端に小さくなります。

```html
<head>
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
</head>
```

- `width=device-width`：表示幅を端末の実際の幅に合わせる
- `initial-scale=1.0`：初期の拡大率を等倍にする

> [!IMPORTANT]
> このタグはレスポンシブ設計の大前提です。CSS でいくらメディアクエリを書いても、この meta タグがなければスマートフォンで意図したレイアウトになりません。

---

## メディアクエリ

`@media` を使うと、「画面幅が〇〇のとき」という条件付きで CSS を適用できます。

```css
/* 画面幅が 768px 以上のときだけ適用 */
@media (min-width: 768px) {
  .container {
    width: 720px;
  }
}
```

よく使う条件は次の2つです。

```css
@media (min-width: 768px) { /* 768px 以上のとき */ }
@media (max-width: 767px) { /* 767px 以下のとき */ }
```

レイアウトを切り替える境目の幅を**ブレークポイント**と呼びます。代表的な目安は次のとおりです。

| 端末 | おおよその幅 |
|------|------|
| スマートフォン | 〜767px |
| タブレット | 768px〜1023px |
| PC | 1024px〜 |

---

## モバイルファースト

レスポンシブ設計では、**小さい画面（スマホ）を基準に CSS を書き、大きい画面向けの調整を `min-width` で追加していく**「モバイルファースト」が推奨されます。

```css
/* 基準：スマホ（1列） */
.gallery {
  display: grid;
  grid-template-columns: 1fr;
  gap: 16px;
}

/* タブレット以上：2列 */
@media (min-width: 768px) {
  .gallery {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* PC 以上：3列 */
@media (min-width: 1024px) {
  .gallery {
    grid-template-columns: repeat(3, 1fr);
  }
}
```

**ポイント**
- 小さい画面の CSS をベースにし、`min-width` で「画面が広がったら上書きする」と考えると整理しやすくなります。
- スマホは表示領域が限られるため、最初から1カラムで設計しておくと崩れにくくなります。

---

## 相対単位

固定の `px` だけでなく、画面や親要素に応じて伸縮する**相対単位**を使うと、レスポンシブにしやすくなります。

```css
.box {
  width: 80%;        /* 親要素の幅に対する割合 */
  max-width: 600px;  /* ただし 600px を超えては広がらない */
  padding: 1rem;     /* ルートの文字サイズ基準（標準で 16px） */
  font-size: 1.125rem;
}

.hero {
  width: 100vw;      /* ビューポート幅の 100%（画面いっぱい） */
  height: 50vh;      /* ビューポート高さの 50% */
}
```

| 単位 | 基準 | 主な用途 |
|------|------|----------|
| `%` | 親要素のサイズ | 幅・高さ |
| `rem` | ルート（`html`）の文字サイズ | 余白・文字サイズ |
| `vw` | ビューポート幅の 1% | 画面幅に追従する幅 |
| `vh` | ビューポート高さの 1% | 画面高さに追従する高さ |

> [!TIP]
> `width: 80%` のように割合で広げつつ、`max-width: 600px` で上限を決めると、大画面では広がりすぎず、小画面では画面に収まる柔軟なボックスになります。よく使う組み合わせです。

---

## 実用例

```css
.container {
  width: 90%;
  max-width: 1100px;
  margin: 0 auto;   /* 左右中央寄せ */
  padding: 1rem;
}

.text {
  font-size: 1rem;
  line-height: 1.7;
}

@media (min-width: 768px) {
  .text {
    font-size: 1.125rem;  /* 画面が広いときは少し大きく */
  }
}
```

---

## まとめ

- レスポンシブ設計の前提として、`<head>` に**ビューポート meta タグ**を必ず入れます。
- **メディアクエリ（`@media`）** で、画面幅に応じて CSS を切り替えます。
- **モバイルファースト**：スマホを基準に書き、`min-width` で大画面向けを追加していくと整理しやすくなります。
- **相対単位（`%` / `rem` / `vw` / `vh`）** を使うと、画面サイズに追従する柔軟なレイアウトになります。
