# CSSの全体像 (カスケード / 特定性 / レイアウトモデル)

## はじめに

CSS（Cascading Style Sheets）は、HTML で作った文書の**見た目**を指定するための言語です。HTML が「何を書くか（構造）」を担当するのに対し、CSS は「どう見せるか（装飾とレイアウト）」を担当します。

たとえば、次の HTML だけでは文字は黒、背景は白の素朴な見た目になります。

```html
<h1 class="title">こんにちは</h1>
<p class="lead">これは段落です。</p>
```

ここに CSS を加えると、色・大きさ・余白・配置を自由にコントロールできます。

```css
.title {
  color: #1d4ed8;
  font-size: 32px;
}

.lead {
  color: #374151;
  line-height: 1.8;
}
```

CSS のルールは「**セレクタ**（どこに適用するか）」と「**宣言ブロック**（どう見せるか）」の組み合わせでできています。

```css
セレクタ {
  プロパティ: 値;
}
```

このレッスンでは、個々のプロパティを覚える前に、CSS を貫く3つの根幹概念 ―― **カスケード**・**特定性**・**レイアウトモデル** ―― を俯瞰します。これらを理解しておくと、「なぜこのスタイルが効かないのか」「なぜ思った場所に表示されないのか」といったつまずきを自分で解決できるようになります。

## カスケードと特定性

CSS の「C」は **Cascading（カスケード＝段階的に流れ落ちる）** を意味します。1つの要素に対して複数のルールが該当したとき、CSS はどれを優先するかを段階的なルールで決定します。

### カスケード：適用順のルール

同じ要素に複数のスタイルが当たる場合、おおまかに次の優先順位で勝者が決まります。

```css
/* 1. 後に書かれたルールが勝つ（同じ強さなら） */
p { color: red; }
p { color: blue; }   /* こちらが適用され、文字は青になる */
```

```html
<!-- 2. インラインstyleは外部CSSより強い -->
<p style="color: green;">この文字は緑になる</p>
```

優先順位の大枠は次のとおりです。

1. `!important` が付いた宣言（多用は避ける）
2. インライン `style` 属性
3. id セレクタ → クラス／属性／擬似クラス → 要素セレクタ（＝特定性）
4. 同じ強さなら、後に書かれたものが勝つ

> [!TIP]
> 「CSS が効かない」ときの大半は、より強いルールに上書きされているのが原因です。ブラウザの開発者ツール（要素を右クリック →「検証」）を開くと、どのルールが勝っているか一目で確認できます。

### 特定性（詳細度）

複数のセレクタが競合したとき、どれが強いかを表す数値が**特定性（specificity／詳細度）** です。`(id の数, クラス・属性・擬似クラスの数, 要素の数)` の3つの組で比較します。

```css
p            { color: black; }  /* (0,0,1) */
.note        { color: blue;  }  /* (0,1,0) → こちらが強い */
#main p      { color: red;   }  /* (1,0,1) → さらに強い */
```

## レイアウトモデル

要素を「どこに、どう並べるか」を決めるのがレイアウトです。CSS には大きく分けて3つの考え方があります。

### 1. 通常フロー（ボックスモデル）

すべての要素は四角い「箱（ボックス）」として扱われ、特に指定しなければ HTML に書いた順に上から下へ積み上がります。この箱の内側の余白・枠線・外側の余白を理解することが、レイアウトの第一歩です。

```css
.card {
  box-sizing: border-box;
  padding: 16px;        /* 内側の余白 */
  border: 1px solid #ccc;
  margin: 24px;         /* 外側の余白 */
}
```

### 2. Flexbox（1次元のレイアウト）

要素を**横一列**または**縦一列**に並べ、間隔や揃え方を柔軟に制御するしくみが Flexbox です。ナビゲーションバーやボタンの横並びなど、1方向の配置に向いています。

```css
.nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
}
```

### 3. Grid（2次元のレイアウト）

行と列の両方を同時に扱い、格子状にレイアウトするのが Grid です。カードの一覧やページ全体の骨組みなど、縦横を組み合わせた配置に向いています。

```css
.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}
```

### レスポンシブ設計

PC・タブレット・スマートフォンなど、画面幅に応じてレイアウトを変える設計を**レスポンシブデザイン**と呼びます。メディアクエリと相対単位を組み合わせて実現します。

```css
.gallery {
  grid-template-columns: 1fr;       /* スマホ：1列 */
}

@media (min-width: 768px) {
  .gallery {
    grid-template-columns: repeat(3, 1fr);  /* PC：3列 */
  }
}
```

### タイポグラフィと色

文字（フォント・行間）と色は、読みやすさと印象を大きく左右する基礎要素です。指定方法を整理しておきましょう。

```css
body {
  font-family: system-ui, sans-serif;
  line-height: 1.7;
  color: #1f2937;
  background: #ffffff;
}
```

## まとめ

- CSS は HTML の**見た目**を指定する言語で、「セレクタ」と「宣言ブロック」で構成されます。
- **カスケード**：複数のルールが競合したとき、段階的な優先順位で勝者が決まります。
- **特定性（詳細度）**：`(id, クラス等, 要素)` の数でセレクタの強さを比較します。スタイルが効かないときは特定性を疑いましょう。
- **レイアウトモデル**：通常フロー（ボックスモデル）を土台に、1次元なら **Flexbox**、2次元なら **Grid** を使い分けます。
- **レスポンシブ設計**で画面幅に対応し、**タイポグラフィと色**で読みやすさを整えます。
