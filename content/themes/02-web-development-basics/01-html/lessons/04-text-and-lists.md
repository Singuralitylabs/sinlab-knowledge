# 見出し・段落・リスト

## 解説

Web ページの文章は、見出し・段落・強調・リストといった基本要素を組み合わせて作ります。
これらを正しく使い分けることで、読みやすく、意味の伝わる文書になります。

---

## 見出し（`<h1>`〜`<h6>`）

見出しは `<h1>` から `<h6>` までの6段階があります。
数字が小さいほど重要度が高く、大きく表示されます。

```html
<h1>記事のタイトル</h1>
<h2>大きな章</h2>
<h3>小さな節</h3>
<h4>さらに細かい項目</h4>
```

**ポイント**

- `<h1>` は、そのページで最も重要な見出し（タイトル）に使います。
- 見出しは**階層を飛ばさず**順番に使います（`<h1>` の次は `<h2>`、その下が `<h3>`）。
- 見出しは「文字を大きくしたいから」使うものではありません。文書の**構造**を表すために使います。大きさは CSS で調整します。

> [!WARNING]
> 「見た目が大きいから」という理由だけで `<h1>` を多用したり、`<h2>` を飛ばして `<h3>` を使ったりするのは避けましょう。見出しの順序は、スクリーンリーダー利用者がページの構造を把握する手がかりになります。

---

## 段落（`<p>`）

通常の本文は `<p>`（paragraph）で囲みます。

```html
<p>これは1つ目の段落です。文章のまとまりごとに p タグで囲みます。</p>
<p>これは2つ目の段落です。段落を分けると、自動的に上下に余白が入ります。</p>
```

**表示結果**

2つの文章が、それぞれ別の段落として上下に間隔を空けて表示されます。

**ポイント**

- 改行したいだけなら `<br>` も使えますが、文章のまとまりは `<p>` で表すのが基本です。
- `<br>` の多用は避け、意味のあるまとまりは段落として区切りましょう。

---

## 強調（`<strong>` と `<em>`）

文章の一部を強調するタグです。見た目だけでなく「意味」を持ちます。

```html
<p>この操作は<strong>取り消せません</strong>。</p>
<p>これは<em>とても</em>重要な点です。</p>
```

**表示結果**

`<strong>` の部分は通常**太字**で、`<em>` の部分は*斜体*で表示されます。

| タグ | 意味 | 標準の見た目 |
|------|------|--------------|
| `<strong>` | 強い重要性（警告・注意など） | 太字 |
| `<em>` | 強調（語調を強める） | 斜体 |

> [!NOTE]
> 単に見た目を太字・斜体にしたいだけなら `<b>`・`<i>` というタグもあります。しかし「内容として重要・強調したい」場合は、意味を持つ `<strong>`・`<em>` を使うのが推奨です。

---

## 箇条書きリスト（`<ul>`）

順序のない箇条書きは `<ul>`（unordered list）と `<li>`（list item）で作ります。

```html
<ul>
  <li>りんご</li>
  <li>みかん</li>
  <li>ぶどう</li>
</ul>
```

**表示結果**

- りんご
- みかん
- ぶどう

---

## 番号付きリスト（`<ol>`）

手順など順序のあるリストは `<ol>`（ordered list）を使います。番号は自動で振られます。

```html
<ol>
  <li>材料を準備する</li>
  <li>野菜を切る</li>
  <li>炒めて煮込む</li>
</ol>
```

**表示結果**

1. 材料を準備する
2. 野菜を切る
3. 炒めて煮込む

---

## リストの入れ子

`<li>` の中にさらにリストを入れると、階層を表せます。

```html
<ul>
  <li>フルーツ
    <ul>
      <li>りんご</li>
      <li>みかん</li>
    </ul>
  </li>
  <li>野菜
    <ul>
      <li>にんじん</li>
    </ul>
  </li>
</ul>
```

---

## 説明リスト（`<dl>`）

「用語」と「その説明」のペアを並べるときは `<dl>`（description list）を使います。

```html
<dl>
  <dt>HTML</dt>
  <dd>Web ページの構造を作る言語。</dd>
  <dt>CSS</dt>
  <dd>Web ページの見た目を整える言語。</dd>
</dl>
```

| タグ | 役割 |
|------|------|
| `<dl>` | 説明リスト全体を囲む |
| `<dt>` | 用語（definition term） |
| `<dd>` | 説明（definition description） |

> [!TIP]
> `<dl>` は、用語集・FAQ・項目と値のペア（例: 「価格: 1,000円」）などに向いています。

---

## まとめ

- 見出しは `<h1>`〜`<h6>` の6段階。階層を飛ばさず順番に使う。
- 本文の段落は `<p>` で囲む。
- 強調は意味を持つ `<strong>`（重要）・`<em>`（強調）を使う。
- 箇条書きは `<ul>`、順序ありは `<ol>`、各項目は `<li>`。
- 用語と説明のペアは `<dl>`/`<dt>`/`<dd>`。
