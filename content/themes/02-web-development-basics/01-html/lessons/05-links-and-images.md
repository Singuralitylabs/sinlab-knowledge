# リンクと画像

## 解説

Web の最大の特徴は、ページ同士が**リンク**でつながっていることです。
また、文章だけでなく**画像**を表示できるのも HTML の重要な機能です。ここでは `<a>`（リンク）と `<img>`（画像）の使い方を学びます。

---

## リンク（`<a>`）

リンクは `<a>`（anchor）タグで作ります。`href` 属性にリンク先の URL を指定します。

```html
<a href="https://www.example.com">Example サイトへ</a>
```

**表示結果**

「Example サイトへ」という文字がリンクとして表示され、クリックすると指定したページに移動します。

---

## リンク先の指定方法（相対パスと絶対パス）

リンク先の書き方には大きく2種類あります。

### 絶対パス（フルURL）

`https://` から始まる完全な URL です。**外部サイト**へのリンクに使います。

```html
<a href="https://www.google.com">Google を開く</a>
```

### 相対パス

**同じサイト内**の別ページへのリンクに使います。現在のファイルから見た位置で指定します。

```html
<!-- 同じ階層にある about.html へ -->
<a href="about.html">運営者について</a>

<!-- サイトのルートから見た /contact へ -->
<a href="/contact">お問い合わせ</a>

<!-- 1つ上の階層にある index.html へ -->
<a href="../index.html">トップに戻る</a>
```

| 書き方 | 意味 |
|--------|------|
| `about.html` | 同じフォルダ内のファイル |
| `pages/help.html` | 下のフォルダ内のファイル |
| `../index.html` | 1つ上のフォルダのファイル |
| `/contact` | サイトのルート（最上位）からの位置 |

---

## 新しいタブで開く（`target` と `rel`）

外部サイトを新しいタブで開きたい場合は `target="_blank"` を指定します。
その際は、セキュリティ対策として `rel="noopener noreferrer"` をあわせて付けます。

```html
<a href="https://www.example.com" target="_blank" rel="noopener noreferrer">
  新しいタブで開く
</a>
```

> [!NOTE]
> `rel="noopener noreferrer"` を付けると、リンク先のページから元のページが不正に操作されるのを防げます。`target="_blank"` を使うときはセットで付ける習慣をつけましょう。

---

## ページ内リンク

`href="#id名"` と書くと、同じページ内の特定の場所へジャンプできます。
ジャンプ先の要素には `id` 属性を付けておきます。

```html
<!-- リンク -->
<a href="#section2">セクション2へ移動</a>

<!-- ジャンプ先 -->
<h2 id="section2">セクション2</h2>
```

---

## 画像（`<img>`）

画像は `<img>` タグで表示します。`<img>` は閉じタグを持たない要素です。

```html
<img src="cat.jpg" alt="窓辺で眠る茶トラの猫" />
```

| 属性 | 役割 |
|------|------|
| `src` | 画像ファイルの場所（URL やパス） |
| `alt` | 画像の内容を説明する代替テキスト |

**ポイント**

- `src` には、リンクと同じく相対パス・絶対パスのどちらも使えます。
- `alt` は画像が表示できないときに代わりに表示され、スクリーンリーダーでも読み上げられます。

> [!IMPORTANT]
> `alt` は必ず指定しましょう。`alt` には「画像が何を表しているか」を具体的に書きます。装飾目的でとくに意味のない画像の場合は、`alt=""`（空文字）にして読み上げ対象から外します。

```html
<!-- 良い例: 内容が伝わる代替テキスト -->
<img src="graph.png" alt="2026年の売上推移を示す折れ線グラフ" />

<!-- 装飾目的の画像は空の alt にする -->
<img src="decoration.png" alt="" />
```

---

## サイズの指定

`width` と `height` 属性で表示サイズ（ピクセル）を指定できます。

```html
<img src="logo.png" alt="会社のロゴ" width="200" height="80" />
```

> [!TIP]
> あらかじめ `width` と `height` を指定しておくと、画像が読み込まれる前にブラウザが表示スペースを確保できるため、レイアウトのガタつきを防げます。

---

## レスポンシブ画像の入り口

スマートフォンとパソコンで画面サイズが大きく異なるため、画面幅に合わせて画像を表示したい場面があります。
入門段階では、まず「画像が画面からはみ出さないようにする」CSS の指定を知っておくと役立ちます。

```html
<img src="photo.jpg" alt="海辺の風景" style="max-width: 100%; height: auto;" />
```

`max-width: 100%` は「親要素の幅を超えない」、`height: auto` は「縦横比を保つ」という意味です。
より高度な手法（`srcset` や `<picture>` で画面サイズごとに別画像を出し分ける）は、後のレッスンで扱います。

---

## まとめ

- リンクは `<a href="...">`。外部サイトは絶対パス、サイト内は相対パスを使う。
- 別タブで開くときは `target="_blank"` と `rel="noopener noreferrer"` をセットで。
- 画像は `<img src="..." alt="...">`。`alt` は必ず指定する。
- `width`/`height` を指定するとレイアウトのガタつきを防げる。
- `max-width: 100%` で画像が画面からはみ出さないようにできる。
