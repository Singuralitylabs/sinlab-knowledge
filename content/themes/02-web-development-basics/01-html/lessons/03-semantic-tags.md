# セマンティクスタグ

## 解説

セマンティクス（semantics）とは「意味」のことです。
**セマンティクスタグ**とは、その内容が「何であるか」を名前で表すタグを指します。

たとえば、ページの最上部にあるロゴやタイトルの領域は `<header>`、メインの内容は `<main>`、最下部の著作権表記などは `<footer>` で囲みます。
タグ名を見ただけで、その部分の役割が分かるのが特徴です。

```html
<body>
  <header>サイトのロゴやタイトル</header>
  <nav>ナビゲーションメニュー</nav>
  <main>ページの主要なコンテンツ</main>
  <footer>著作権表記など</footer>
</body>
```

---

## 主なセマンティクスタグ

| タグ | 意味・役割 |
|------|------------|
| `<header>` | ページやセクションの先頭部分（ロゴ・タイトル・見出しなど） |
| `<nav>` | ナビゲーション（メニューやリンク集） |
| `<main>` | そのページの主要コンテンツ（1ページに1つだけ） |
| `<article>` | それ単体で完結する内容（記事・投稿・ニュースなど） |
| `<section>` | 意味のあるまとまり（章・テーマごとの区切り） |
| `<aside>` | 本筋から外れた補足（サイドバー・関連情報・広告など） |
| `<footer>` | ページやセクションの末尾部分（著作権・連絡先など） |

---

## 全体構成の例

実際のページでは、これらを組み合わせて文書全体の構造を表します。

```html
<body>
  <header>
    <h1>料理ブログ</h1>
    <nav>
      <a href="/">ホーム</a>
      <a href="/recipes">レシピ一覧</a>
      <a href="/about">運営者について</a>
    </nav>
  </header>

  <main>
    <article>
      <h2>かんたんカレーの作り方</h2>
      <section>
        <h3>材料</h3>
        <p>玉ねぎ、にんじん、じゃがいも、カレールー</p>
      </section>
      <section>
        <h3>手順</h3>
        <p>野菜を切り、炒めて、煮込みます。</p>
      </section>
    </article>

    <aside>
      <h2>関連レシピ</h2>
      <p>シチュー、ハヤシライス</p>
    </aside>
  </main>

  <footer>
    <p>&copy; 2026 料理ブログ</p>
  </footer>
</body>
```

**ポイント**

- `<main>` は1ページに1つだけ置きます。
- `<article>` は「切り出しても意味が通る」内容に使います。たとえばブログ記事は、それ単体で読めるので `<article>` が適切です。
- `<section>` は「見出しを伴うまとまり」を表すときに使います。

---

## `<div>` との違い

`<div>` は**意味を持たない**汎用的な箱です。
次の2つは、ブラウザでの見た目はほとんど同じになります。しかし、伝わる「意味」がまったく違います。

```html
<!-- 意味を持たない div だけの構成 -->
<div>サイトのタイトル</div>
<div>メインの内容</div>
<div>著作権表記</div>

<!-- 意味を持つセマンティクスタグの構成 -->
<header>サイトのタイトル</header>
<main>メインの内容</main>
<footer>著作権表記</footer>
```

セマンティクスタグを使うと、次のようなメリットがあります。

- **検索エンジン**がページ構造を正しく理解しやすくなる（SEO に有利）。
- **スクリーンリーダー**が「ここはナビゲーション」「ここがメイン」と読み上げ、利用者がページ内を移動しやすくなる。
- **開発者**がコードを読んだとき、各部分の役割がひと目で分かる。

> [!TIP]
> `<div>` が不要というわけではありません。「ちょうど当てはまる意味のタグがない」「単に CSS で見た目をまとめたいだけ」という場合は `<div>` を使います。**意味のある部分にはセマンティクスタグ、意味のない箱には `<div>`** と使い分けましょう。

---

## まとめ

- セマンティクスタグは、内容が「何であるか」を名前で表すタグ。
- `<header>` `<nav>` `<main>` `<article>` `<section>` `<aside>` `<footer>` が代表例。
- `<main>` は1ページに1つだけ。
- `<div>` は意味を持たない汎用的な箱。当てはまる意味のタグがあればそちらを優先する。
- 意味に合ったタグ選びが、SEO・アクセシビリティ・可読性すべてに効いてくる。
