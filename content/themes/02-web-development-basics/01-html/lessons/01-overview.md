# HTMLの全体像 (文書構造 / セマンティクス / アクセシビリティの位置付け)

## はじめに

### HTMLとは？

HTML（HyperText Markup Language）は、Webページの「骨組み」を作るためのマークアップ言語です。
私たちが普段ブラウザで見ている文章・見出し・リスト・リンク・画像・入力フォームなどは、すべて HTML のタグによって意味づけされています。

「マークアップ」とは、テキストにタグという目印を付けて「これは見出し」「これは段落」「これはリンク」と**意味を与える**ことを指します。たとえば次のように書きます。

```html
<h1>はじめてのHTML</h1>
<p>これは段落です。</p>
```

`<h1>` は「最も重要な見出し」、`<p>` は「段落」を表します。ブラウザはこのタグを読み取り、見出しを大きく、段落を通常の文章として表示します。

> [!NOTE]
> HTML は「見た目」を細かく整えるための言語ではありません。色や余白などの装飾は CSS が、動きや処理は JavaScript が担当します。HTML はあくまで**文書の構造と意味**を表現する役割です。

### Web を支える3つの言語

Web ページは、役割の異なる3つの言語が組み合わさってできています。

| 言語 | 役割 | 例え |
|------|------|------|
| **HTML** | 構造・意味（骨組み） | 建物の骨組み |
| **CSS** | 見た目・装飾（スタイル） | 内装・塗装 |
| **JavaScript** | 動き・処理（振る舞い） | 電気・設備 |

このレッスンでは、その土台となる HTML を学びます。

---

## なぜHTMLを学ぶのか

- **すべての Web の土台**：あらゆる Web サイト・Web アプリは HTML の上に成り立っています。CSS も JavaScript も、HTML という土台がなければ機能しません。
- **正しい構造がすべてに効く**：意味を正しく表した HTML は、検索エンジン（SEO）・スクリーンリーダー・ブラウザの自動補助など、あらゆる仕組みに好影響を与えます。
- **生成AIやツールとの連携**：HTML は機械が解釈しやすい構造化テキストです。構造が正しいほど、ツールやAIが内容を正確に扱えます。
- **学習コストが低い**：覚えるべき基本タグは多くありません。短時間で「読める・書ける」状態に到達できます。

## このモジュールで学ぶこと

HTML の全体像を、次の6つのトピックに分けて学びます。各トピックの要点をここで掴み、詳しい解説は続く各レッスンで確認してください。

### 1. 文書の基本構造

すべての HTML ファイルには、`<!DOCTYPE html>` から始まる決まった骨組みがあります。
`<html>` の中に、ページの設定情報を書く `<head>` と、実際に表示される内容を書く `<body>` が並びます。この型を覚えることが最初の一歩です。

```html
<!DOCTYPE html>
<html lang="ja">
  <head>
    <meta charset="UTF-8" />
    <title>ページのタイトル</title>
  </head>
  <body>
    <h1>こんにちは</h1>
  </body>
</html>
```

### 2. セマンティクスタグ

`<header>`・`<nav>`・`<main>`・`<article>`・`<footer>` など、**意味を持つタグ**を使うと、文書のどこが何の役割を持つのかが明確になります。
意味を持たない `<div>` を並べるよりも、内容に合ったタグを選ぶことで、人にも機械にも分かりやすい HTML になります。

### 3. 見出し・段落・リスト

文章の中身は、見出し `<h1>`〜`<h6>`、段落 `<p>`、強調 `<strong>`/`<em>`、リスト `<ul>`/`<ol>`/`<dl>` といった要素で構成します。
見出しを正しい順序で使い、内容を段落やリストに整理することが、読みやすい文書の基本です。

### 4. リンクと画像

`<a>` でほかのページや外部サイトへのリンクを、`<img>` で画像を表示します。
リンク先の指定方法（相対パス・絶対パス）や、画像に必ず付けるべき `alt`（代替テキスト）など、実用上欠かせないポイントを押さえます。

### 5. フォーム要素

問い合わせ・ログイン・検索など、ユーザーからの入力を受け取る部分は `<form>` と各種入力要素で作ります。
`<input>`・`<label>`・`<textarea>`・`<select>`・`<button>` の使い方と、`required` などの基本的な入力チェック（バリデーション）を学びます。

### 6. アクセシビリティ基礎

アクセシビリティとは、年齢や障害の有無、利用環境にかかわらず、誰もが Web を使えるようにする考え方です。
適切なタグの選択・`alt`・見出し階層・`<label>`・キーボード操作といった、HTML の段階でできる基礎的な配慮を学びます。

## まとめ

- **HTML は Web の骨組み**であり、CSS（見た目）・JavaScript（動き）の土台になります。
- すべての HTML ファイルには `<!DOCTYPE html>` から始まる**決まった基本構造**があります。
- `<div>` を並べるのではなく、**意味を持つセマンティクスタグ**を選ぶことで、人にも機械にも分かりやすくなります。
- 見出し・段落・リスト・リンク・画像・フォームといった**基本要素**を組み合わせて文書を作ります。
- 正しい HTML は、そのまま**アクセシビリティと SEO の土台**になります。
