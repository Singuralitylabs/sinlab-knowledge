# Elements：HTMLのリアルタイム編集

## 解説

Elementsパネルの左側には、現在表示されているページのDOM構造がツリー形式で表示されます。ここでは、実際に配信されているHTMLファイルを書き換えるのではなく、**ブラウザがメモリ上で保持している表示状態（レンダリング結果）を直接いじる**ことができます。

### 主な編集操作

| 操作 | やり方 | 用途 |
|------|--------|------|
| テキスト・属性の変更 | 要素をダブルクリック | 見出しの文言や`class`属性を試しに変えたい |
| 構造の書き換え | 右クリック→「Edit as HTML」 | 親要素を含めてまとめてコードを編集したい |
| ノードの移動 | ツリー上でドラッグ＆ドロップ | 要素の表示順を試しに入れ替えたい |
| ノードの削除 | 要素を選択して`Delete`キー | 邪魔な要素を一時的に非表示にしたい |

---

## ありがちなつまずき

### 1. 編集内容が保存されたと勘違いする

```text
❌ Elementsパネルでテキストを書き換えて満足し、そのまま作業を終える
   → リロードすると元のHTMLに戻ってしまい、変更が消えたと驚く

✅ Elementsパネルの変更はあくまで「確認用」。実際にファイルを直すのはエディタ側
```

### 2. 「Edit as HTML」で構造を壊してしまう

閉じタグを消したり属性のクォートを崩したりすると、その場でレイアウトが崩れることがあります。慌てず`Ctrl/Cmd + Z`（Elementsパネル内の編集履歴の取り消し）を試すか、ページをリロードして最初からやり直します。

---

## 実用例

### CSSクラスを一時的に付け替えて見た目を確認する

デザイン変更の相談を受けたとき、実装前にElementsパネルで対象要素の`class`属性を書き換えれば、コードを触らずに見た目の変化を関係者にその場で見せられます。

### 邪魔な広告・モーダルを一時的に消してスクリーンショットを撮る

固定表示のバナーやCookie同意モーダルが画面を覆っている場合、該当要素を選択して`Delete`キーで一時的に消してから、レイアウト確認用のスクリーンショットを撮ると作業がはかどります（リロードすれば元に戻ります）。
