# ディレクトリ移動（pwd・cd・ls）

## 解説

ターミナル操作の土台になるのが、「**現在地を確認する → 中身を見る → 移動する**」という3つの動作です。それぞれに対応するコマンドが `pwd`・`ls`・`cd` です。この3つを自在に使えるようになれば、ファイルシステムの中を迷わず歩き回れます。

| コマンド | 由来 | 役割 |
|----------|------|------|
| `pwd` | **P**rint **W**orking **D**irectory | いまどこにいるか（現在地）を表示 |
| `ls` | **l**i**s**t | 現在地にあるファイル・フォルダの一覧を表示 |
| `cd` | **C**hange **D**irectory | 別のフォルダへ移動 |

GUI でいえば、`pwd` は「いま開いているフォルダのパス欄」、`ls` は「フォルダを開いて中身を見ること」、`cd` は「フォルダをダブルクリックして開くこと」に相当します。

---

## コマンドサンプル

### pwd — 現在地を確認

```bash
pwd          # カレントディレクトリの絶対パスを表示
```

### ls — 一覧を表示

```bash
ls           # ファイル・フォルダ名を一覧表示
ls -l        # 詳細表示（権限・サイズ・更新日時など）
ls -a        # 隠しファイル（. で始まる）も表示
ls -la       # 詳細 + 隠しファイル（オプションはまとめて書ける）
ls -lh       # サイズを読みやすい単位（K, M, G）で表示
ls projects  # 指定したフォルダの中身を表示
ls *.md      # .md で終わるファイルだけ表示
```

### cd — 移動

```bash
cd projects        # 現在地の中の projects へ（相対パス）
cd /Applications   # 絶対パスで移動
cd ..              # 1つ上のフォルダ（親）へ
cd ~               # ホームディレクトリへ
cd                 # 引数なしでもホームへ（~ と同じ）
cd -               # 直前にいたフォルダへ戻る
```

`cd -`（ハイフン）は地味ですが便利で、2つのフォルダを行ったり来たりするときに重宝します。

## 実行結果

```text
$ pwd
/Users/taro

$ ls
Applications  Desktop  Documents  Downloads  projects

$ ls -la
total 8
drwxr-xr-x  12 taro  staff   384  6  1 10:00 .
drwxr-xr-x   5 root  admin   160  5 20 09:00 ..
-rw-r--r--   1 taro  staff   220  5 20 09:00 .zshrc
drwx------+  4 taro  staff   128  6  1 09:30 Documents
drwx------+  6 taro  staff   192  6  1 09:30 projects

$ cd projects
$ pwd
/Users/taro/projects

$ cd -
/Users/taro
```

### `ls -l` の見方

```text
drwxr-xr-x  12 taro  staff   384  6  1 10:00 Documents
│└┬─┘└┬─┘    │   │     │      │   └─ 更新日時      └─ 名前
│ │   │      │   │     │      └─ サイズ（バイト）
│ │   │      │   │     └─ グループ
│ │   │      │   └─ 所有者
│ │   │      └─ リンク数
│ │   └─ その他のユーザーの権限
│ └─ グループの権限 / 所有者の権限
└─ 先頭が d ならフォルダ、- ならファイル
```

最初のうちは、先頭が `d` か `-`（フォルダかファイルか）と、一番右の名前だけ見れば十分です。

## よくある間違い

### 1. 移動したいフォルダ名のスペルミス・大文字小文字

```bash
# ❌ Documents を documents と打つ（大文字小文字は区別される）
cd documents
# → cd: no such file or directory: documents

# ✅ 正確に打つか、タブ補完を使う（doc まで打って Tab）
cd Documents
```

フォルダ名は **タブ補完**（途中まで打って `Tab`）を使えば、打ち間違いも防げて速いです。

### 2. ファイルに対して cd しようとする

```bash
# ❌ cd できるのはフォルダだけ。ファイルには移動できない
cd report.md
# → cd: not a directory: report.md
```

`cd` の引数はフォルダ（ディレクトリ）です。`ls -l` で先頭が `d` のものだけが移動先になれます。

### 3. 隠しファイルが見えずに「無い」と思い込む

```bash
# .zshrc や .gitignore は ls だけでは表示されない
ls          # 見えない
ls -a       # ✅ . で始まる隠しファイルも表示される
```

`.` で始まるファイル・フォルダは「隠しファイル」として、`ls` だけでは表示されません。`-a` をつけて確認しましょう。

## 実用例

### 深いフォルダへ一気に移動して、すぐ戻る

```bash
cd ~/projects/my-app/src/components   # 深い場所へ一気に移動
ls                                     # 中身を確認
cd -                                   # さっきいた場所へ戻る
```

### 移動せずに別フォルダの中身だけ覗く

```bash
# わざわざ cd しなくても、ls にパスを渡せば中身が見える
ls ~/projects/my-app
ls ../another-app/src
```

## 実習

### 課題1：3コマンドのリズムを体に覚えさせる

1. ターミナルを開き、`pwd` で現在地を確認してください
2. `ls` で見えたフォルダのどれかに `cd` で移動してください
3. 移動先で再び `pwd` と `ls` を実行してください
4. この「`pwd` → `ls` → `cd`」を3回ほど繰り返し、好きな場所まで降りていってください

### 課題2：オプションの違いを比べる

1. 同じフォルダで `ls`・`ls -l`・`ls -a`・`ls -la` を順に実行してください
2. それぞれ表示がどう変わるか観察してください
3. 隠しファイル（`.` で始まるもの）がどのオプションで見えるか確認してください

### 課題3：`cd ..` と `cd -` を使い分ける

1. 2〜3階層深いフォルダに移動してください
2. `cd ..` で1つずつ上がってみてください
3. 一度ホーム（`cd ~`）に戻り、`cd -` で直前のフォルダに戻れることを確認してください
