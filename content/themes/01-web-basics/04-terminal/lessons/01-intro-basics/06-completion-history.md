# タブ補完とコマンド履歴

## 解説

ここまでで「ターミナルで操作する」ことはできるようになりました。最後に、その操作を**速く・正確に**行うためのスキルを身につけましょう。**タブ補完**と**コマンド履歴**は、ターミナルに慣れた人が必ず使っている2大テクニックです。

長いフォルダ名を一字一句タイプしたり、同じコマンドを毎回打ち直したりする必要はありません。この2つを使えるかどうかで、作業スピードが大きく変わります。

---

## タブ補完

途中まで入力して **`Tab` キー**を押すと、残りを自動で補完してくれる機能です。フォルダ名・ファイル名・コマンド名のどれにも効きます。

```bash
# Documents と打ちたいとき、Doc まで入力して Tab
cd Doc[Tab]      → cd Documents/   に補完される

# 候補が1つに絞れないときは、もう一度 Tab で候補一覧を表示
cd D[Tab][Tab]
Desktop/    Documents/    Downloads/
```

### タブ補完のメリット

- **速い**：長い名前も数文字＋ `Tab` で済む
- **打ち間違いが減る**：実在する名前しか補完されないので、スペルミスやタイプミスが起きない
- **存在確認になる**：`Tab` で補完されない＝そのファイル/フォルダは（その場所に）無い、と分かる

> **補足**：候補が複数あるとき、bash は2回目の `Tab` で一覧表示、zsh は（設定によっては）候補を順番に切り替えることもある、といった細かな挙動の違いがあります。どちらも「`Tab` を押す」という基本は同じです。

## コマンド履歴

過去に打ったコマンドは履歴として記録されており、呼び出して再利用できます。

### 矢印キーで呼び出す

```text
↑ キー   … 1つ前のコマンドを表示（押すたびにさらに過去へ）
↓ キー   … 1つ後（新しい方）のコマンドへ
```

直前のコマンドをもう一度実行したいときは、`↑` を1回押して `Enter` するだけです。

### history コマンドで一覧表示

```bash
history          # これまでのコマンド履歴を番号つきで一覧表示
history -20      # 直近20件だけ表示（zsh）。bash では history 20
!42              # 履歴番号42のコマンドを再実行
!!               # 直前のコマンドを再実行
```

### Ctrl + R で履歴を検索

`Ctrl + R` を押すと、履歴をキーワードで**逆検索**できます。長いコマンドを思い出して打ち直す必要がありません。

```text
(reverse-i-search)`git': git commit -m "初回コミット"
```

| 操作 | 動作 |
|------|------|
| `Ctrl + R` | 逆検索を開始 |
| 文字を入力 | その文字を含む直近のコマンドを表示 |
| `Ctrl + R`（再度） | さらに前の候補へ |
| `Enter` | そのコマンドを実行 |
| `Esc` / `→` | 検索を確定してコマンドを編集できる状態に |
| `Ctrl + C` | 検索をキャンセル |

## 知っておくと便利なショートカット

| ショートカット | 動作 |
|----------------|------|
| `Tab` | 補完 |
| `↑` / `↓` | 履歴をたどる |
| `Ctrl + R` | 履歴を検索 |
| `Ctrl + C` | 実行中のコマンドを中断する |
| `Ctrl + L` | 画面をクリアする（`clear` と同じ） |
| `Ctrl + A` | 行の先頭へカーソル移動 |
| `Ctrl + E` | 行の末尾へカーソル移動 |
| `Ctrl + U` | カーソルより前を削除 |

`Ctrl + C` は特に重要です。コマンドが終わらない・固まったと感じたら、まず `Ctrl + C` で中断を試しましょう。

## よくある間違い

### 1. 長いコマンドを毎回手で打ち直す

```bash
# ❌ さっき打った長いコマンドをもう一度ゼロから入力する
git commit -m "ヘッダーのレイアウトを修正"

# ✅ ↑ キーで呼び出す、または Ctrl + R で "commit" を検索
```

「さっき打ったな」と思ったら、まず `↑` か `Ctrl + R` です。

### 2. タブ補完を使わず手入力してスペルミス

```bash
# ❌ 長いフォルダ名を手打ちして打ち間違える
cd componnets   # typo で no such file or directory

# ✅ comp まで打って Tab。実在する名前だけが補完される
cd comp[Tab]    → cd components/
```

### 3. 固まったときに閉じてしまう

```text
# コマンドが終わらない／プロンプトが返ってこない
→ いきなりウィンドウを閉じる前に、まず Ctrl + C を試す
→ less などの閲覧中なら q
```

## 実習

### 課題1：タブ補完を体感する

1. ホームで `cd ` まで打ち、`Tab` を2回押して候補一覧を表示してください
2. フォルダ名の頭文字を1〜2文字打ってから `Tab` で補完してください
3. 補完されない名前（存在しないフォルダ）を打って `Tab` を押し、反応しないことを確認してください

### 課題2：履歴を呼び出す

1. `pwd`・`ls`・`whoami` を順に実行してください
2. `↑` キーを何度か押して、それぞれが呼び出されることを確認してください
3. `history` で履歴一覧を表示し、`!番号` で好きなコマンドを再実行してください

### 課題3：Ctrl + R で検索する

1. `Ctrl + R` を押してください
2. さっき打ったコマンドの一部（例：`who`）を入力してください
3. 候補が表示されたら `Enter` で実行、または `Esc` で編集できることを確認してください
