# ヘルプの引き方と便利なTips

## 解説

コマンドの使い方をすべて暗記する必要はありません。プロのエンジニアでも、オプションの細かい指定はその都度調べます。大事なのは「**分からないときに自分で調べる方法**」を知っていることです。あわせて、知っておくと作業が楽になる小ワザも紹介します。

---

## ヘルプの引き方

### --help — その場で使い方を表示

多くのコマンドは `--help` オプションで簡単な使い方を表示します。

```bash
ls --help            # ls の使い方とオプション一覧
mkdir --help
git --help           # ツールによっては -h でも同じ
```

### man — マニュアルを読む

`man`（manual）はより詳しいマニュアルを表示します。`less` と同じ操作で読め、`q` で終了します。

```bash
man ls               # ls の詳細マニュアルを表示
man cp
```

| キー | 動作 |
|------|------|
| `Space` | 次のページ |
| `/keyword` | キーワード検索 |
| `q` | 終了 |

> **補足**：`ls --help` は macOS の標準 `ls` では使えないことがあります（`man ls` を使ってください）。Git Bash や Linux では `--help` が使えます。コマンドによって `--help` か `man` のどちらかが効く、と覚えておけば十分です。

### tldr — 例で手早く知りたいとき（任意）

`man` は詳しすぎて読むのが大変なことも。`tldr` は「よく使う例」だけを見せてくれる便利ツールです（別途インストールが必要）。

```bash
tldr tar             # tar の代表的な使い方を例で表示
```

## 便利なTips

### ワイルドカード（*）でまとめて指定

`*`（アスタリスク）は「任意の文字列」を表し、複数のファイルをまとめて指定できます。

```bash
ls *.md              # .md で終わるファイルをすべて表示
rm *.tmp             # .tmp で終わるファイルをすべて削除
cp src/*.js backup/  # src 内の .js ファイルをすべて backup へコピー
ls report-*          # report- で始まるファイルをすべて表示
```

> [!CAUTION]
> `rm *` のようなワイルドカード付きの削除は、思った以上に多くのファイルを消すことがあります。実行前に、同じパターンで **まず `ls`** して対象を確認しましょう（例：`ls *.tmp` で確認 → 問題なければ `rm *.tmp`）。

### 画面のクリアと中断

```bash
clear                # 画面表示をクリア（Ctrl + L でも同じ）
# Ctrl + C            … 実行中のコマンドを中断する
```

### コマンドをつなげて連続実行

```bash
mkdir my-app && cd my-app    # 成功したら次を実行（&&）
git add . && git commit -m "更新"
```

`&&` は「前のコマンドが成功したら次を実行」という意味で、よく使う連結方法です。

### 直前のコマンドを sudo で再実行

```bash
# 権限不足で失敗したとき
npm install -g something     # Permission denied...
sudo !!                      # 直前のコマンドを管理者権限で実行し直す
```

> [!CAUTION]
> `sudo !!` は直前のコマンドを**内容を確認せずにそのまま管理者権限で再実行**します。意図しないコマンドを管理者権限で動かすと被害が大きいため、実行前に必ず直前のコマンドを確認しましょう。
>
> ```bash
> history | tail -n 1   # 直前のコマンドを表示して確認してから
> sudo !!               # 問題なければ管理者権限で再実行
> ```

## よくある間違い

### 1. `man` から抜けられない

```text
man で開いたマニュアルが閉じられない
→ q キーで終了。less と同じ操作です
```

### 2. ワイルドカードの確認を省く

```bash
# ❌ いきなり削除して、消すつもりのなかったファイルまで消す
rm temp*

# ✅ まず ls で対象を確認してから
ls temp*
rm temp*
```

### 3. オプションを覚えようとして手が止まる

オプションは暗記するものではありません。「`-r` はフォルダ向け」「`-a` は隠しファイルも」くらいの感覚を持っておき、細かいことは `--help` / `man` で調べれば十分です。

## 実用例

### 知らないコマンドに出会ったときの調べ方

```bash
# 1. まず --help で概要をつかむ
some-command --help

# 2. 詳しく知りたければ man
man some-command

# 3. 使用例が欲しければ Web 検索や tldr
```

### まとめて整理する

```bash
ls *.log             # ログファイルを確認
mkdir logs           # 保管用フォルダを作成
mv *.log logs/       # まとめて移動
```

## 次の一歩

基礎編はこれで完了です。お疲れさまでした。

## 実習

### 課題1：ヘルプを引く

1. `man ls`（または `ls --help`）を開き、`-l` 以外のオプションを1つ見つけてください
2. `q` で終了してください
3. 見つけたオプションを実際に `ls` で試してみてください

### 課題2：ワイルドカードを使う

1. `touch a.txt b.txt c.md d.md` で4つのファイルを作ってください
2. `ls *.txt` と `ls *.md` で、それぞれが何を表示するか確認してください
3. `ls *.md` で対象を確認してから、`rm *.md` で `.md` ファイルだけを削除してください

### 課題3：コマンドを連結する

1. `mkdir test-dir && cd test-dir && pwd` を実行し、フォルダ作成・移動・確認が一度に行われることを確認してください
2. `cd ~ && rm -r test-dir` で後片付けをしてください（実行前に対象を確認！）
