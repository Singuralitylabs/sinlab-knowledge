# ターミナルの発展テクニック

## はじめに

基礎編・応用編では、コマンドを1つずつ、あるいは組み合わせて使う方法を学びました。発展編では、ターミナルをさらに使いこなすための2つのテーマを扱います。

- **シェルスクリプト**：複数のコマンドをファイルにまとめ、**一連の作業を自動化**する
- **Vim**：ターミナル上で完結する**テキストエディタ**を使えるようにする（おまけ）

どちらも「知っていると一段上の作業ができる」スキルです。すぐに全部使いこなす必要はありませんが、概要を知っておくと、いざ必要になったときに困りません。

> [!NOTE]
> **Windows をお使いの方へ**
> 発展編も bash / zsh を前提にしています。**Git Bash** または **WSL** を使えば、シェルスクリプトも Vim も本文どおりに動きます。

---

## シェルスクリプトで自動化する

毎回同じコマンドを順番に打っているなら、それらをファイルに書いておき、一度の実行でまとめて動かせます。これが**シェルスクリプト**です。プロジェクトのセットアップやビルド・デプロイなど、繰り返す作業を自動化できます。

```bash
#!/bin/bash
echo "セットアップを開始します"
mkdir -p src dist
npm install
echo "完了しました"
```

変数・条件分岐（`if`）・繰り返し（`for`）といったプログラミングの基本要素も使え、ちょっとしたツールを自分で作れるようになります。

## Vim を使えるようにする（おまけ）

サーバ上での設定ファイル編集や `git commit` のメッセージ入力など、**ターミナルから離れずにテキストを編集したい**場面があります。そのとき登場するのが **Vim** です。

Vim は「モード」という独特の操作体系を持ち、最初は戸惑いますが、最低限「**開く・編集する・保存して終了する**」だけ覚えておけば、いざというときに困りません。とくに「Vim から抜けられない！」という有名なつまずきは、ここで解消しておきましょう。

::detail{slug="vim"}

## まとめ

発展編では、シェルスクリプトによる自動化と、ターミナル上のエディタ Vim を紹介しました。

シェルスクリプトは「よく繰り返す手作業を、書いて・実行して・使い回す」ことで、日々の作業を効率化してくれます。Vim は、最低限の操作（挿入モードで編集 → `Esc` → `:wq` で保存終了）を知っておくだけで、ターミナルだけで作業を完結できる安心感が得られます。

### 次のステップ

- **Git モジュール** に進みましょう。`git commit` ではエディタ（環境によっては Vim）が開くことがあり、ここで学んだ操作が役立ちます。
- シェルスクリプトの知識は、CI/CD やビルドスクリプトを読む土台になります。
