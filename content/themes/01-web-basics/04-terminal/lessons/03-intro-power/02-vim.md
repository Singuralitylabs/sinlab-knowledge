# Vim の使い方（おまけ）

## 解説

**Vim**（ヴィム）は、ターミナル上で動くテキストエディタです。マウスを使わず、キーボードだけで高速に編集できるのが特徴です。

ふだんは VS Code のようなエディタで十分ですが、次のような場面では Vim を避けて通れません。

- **サーバ上での編集**：SSH で接続した先に GUI エディタはなく、Vim（や類似の `nano`）で設定ファイルを直す
- **`git commit` のメッセージ入力**：環境によっては、コミット時に Vim が自動で開く
- **ちょっとした確認・修正**：ターミナルから離れずにサッと直したいとき

Vim は奥が深いですが、このページのゴールは **「開く・少し編集する・保存して終了する」ができること**、そして有名な「**Vim から抜けられない問題**」を解消することです。それだけ知っていれば、いざというとき困りません。

---

## 最重要：モードという考え方

Vim には**モード**という独特の仕組みがあります。これを知らないと「文字を打ったのに変な動きをする」と混乱します。

| モード | 役割 | 入り方 |
|--------|------|--------|
| **ノーマルモード** | 移動・コマンド操作（起動直後はこれ） | `Esc` を押す |
| **挿入モード** | 文字を入力する | `i` を押す |
| **コマンドラインモード** | 保存・終了などの命令 | `:` を押す |

ポイントは、**起動直後は「ノーマルモード」で、そのままでは文字を入力できない**こと。文字を打つにはまず `i` で挿入モードに入り、編集が終わったら `Esc` でノーマルモードに戻ります。

```text
        i を押す
ノーマル ─────────→ 挿入（文字入力できる）
  ↑                    │
  └──── Esc を押す ─────┘
```

## まず覚える最小操作

### 開く

```bash
vim memo.txt        # ファイルを開く（無ければ新規作成）
```

### 編集する

1. `i` を押して**挿入モード**に入る（画面下に `-- INSERT --` と出る）
2. ふつうに文字を入力する
3. 終わったら `Esc` で**ノーマルモード**に戻る

### 保存・終了する（最重要）

ノーマルモード（`Esc` を押した状態）で `:` を打ち、続けて入力します。

| 入力 | 動作 |
|------|------|
| `:w` | 保存する（write） |
| `:q` | 終了する（quit） |
| `:wq` | 保存して終了（最頻出） |
| `:q!` | 保存せず強制終了（変更を捨てる） |

> [!IMPORTANT]
> **「Vim から抜けられない！」を解決する**
> 多くの人が最初にハマるのがこれです。落ち着いて次の順で操作してください。
> 1. **`Esc`** を押す（どのモードにいても、まずノーマルモードに戻る）
> 2. `:q!` と入力して `Enter`（変更を破棄して終了）
> 3. 保存して終わりたいなら `:wq` と入力して `Enter`
>
> つまり **「`Esc` → `:wq`（または `:q!`）→ `Enter`」** を覚えておけば、必ず抜けられます。

## 基本の移動・編集

ノーマルモードでのよく使う操作です（最初は矢印キーでの移動でも構いません）。

| キー | 動作 |
|------|------|
| `h` `j` `k` `l` | 左・下・上・右へ移動（矢印キーでも可） |
| `i` | カーソル位置で挿入モード |
| `a` | カーソルの**次**から挿入モード |
| `o` | 下に新しい行を作って挿入モード |
| `x` | 1文字削除 |
| `dd` | 1行削除 |
| `yy` | 1行コピー（yank） |
| `p` | 貼り付け（paste） |
| `u` | 元に戻す（undo） |
| `/文字列` | 検索（`n` で次の候補へ） |

```text
$ vim memo.txt

（画面が Vim に切り替わる）
~
~
"memo.txt" [New]                          0,0-1   All

# i を押す → -- INSERT -- が下に表示される
# 「買い物リスト」と入力
# Esc を押す → ノーマルモードに戻る
# :wq と入力して Enter

$ cat memo.txt
買い物リスト
```

## よくある間違い

### 1. 起動直後にいきなり文字を打つ

```text
# ノーマルモードのまま "hello" と打つと、各文字がコマンドとして解釈されて
# カーソルが飛んだり一部が消えたりする

→ まず i で挿入モードに入ってから入力する
```

### 2. 終了しようとして文字が入力される

```text
# 挿入モードのまま :wq と打つと、本文に ":wq" と書き込まれてしまう

→ 先に Esc を押してノーマルモードに戻ってから :wq
```

### 3. 保存できずに終了できない

```text
E37: No write since last change （変更が保存されていません）

→ 保存して終了するなら :wq
→ 変更を捨てて終了するなら :q!
```

## 実用例

### git commit で開いた Vim を閉じる

`git commit`（`-m` なし）を実行すると、環境によっては Vim が開きます。

1. `i` で挿入モードに入り、コミットメッセージを入力
2. `Esc` でノーマルモードに戻る
3. `:wq` で保存して終了 → コミットが確定する

メッセージを書かずにやめたい場合は `:q!` で終了すれば、コミットが中止されます。

### エディタを Vim 以外に変えたいとき

「Vim は難しいので VS Code を使いたい」場合は、既定エディタを変更できます（応用編「環境変数」参照）。

```bash
export EDITOR="code --wait"   # git などが VS Code を開くようになる
```

## 実習

### 課題1：開いて保存して終了する

1. `vim practice.txt` でファイルを開いてください
2. `i` で挿入モードに入り、好きな文章を1行入力してください
3. `Esc` → `:wq` → `Enter` で保存して終了してください
4. `cat practice.txt` で、入力した内容が保存されていることを確認してください

### 課題2：「抜けられない」を自力で解決する

1. もう一度 `vim practice.txt` を開いてください
2. 何か入力した後、**保存せずに**終了してみましょう（`Esc` → `:q!` → `Enter`）
3. `cat practice.txt` で、変更が保存されていない（破棄された）ことを確認してください

### 課題3：基本の編集操作

1. `vim practice.txt` を開き、ノーマルモードで `dd`（行削除）・`u`（元に戻す）を試してください
2. `o` で新しい行を作って文字を入力し、`Esc` → `:wq` で保存してください
3. `/` で文字列を検索し、`n` で次の候補へ移動できることを確認してください
