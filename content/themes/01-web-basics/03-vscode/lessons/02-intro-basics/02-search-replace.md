# 検索と置換

## 解説

VS Code の検索は **エディタ内検索** と **ワークスペース全体検索** の 2 階層に分かれます。どちらも UI は似ていますが、扱える対象と機能の充実度が異なります。

| 検索の種類 | 対象 | 起動 |
|------------|------|------|
| **エディタ内検索** | 現在開いているファイルのみ | `Cmd + F` / `Ctrl + F` |
| **エディタ内置換** | 同上 | `Cmd + Option + F` / `Ctrl + H` |
| **ワークスペース検索** | 開いているフォルダ全体 | `Cmd + Shift + F` / `Ctrl + Shift + F` |
| **ワークスペース置換** | 同上 | `Cmd + Shift + H` / `Ctrl + Shift + H` |

---

## エディタ内検索の操作

| 操作 | macOS | Windows / Linux |
|------|-------|-----------------|
| 次の一致へ移動 | `Cmd + G` または `Enter` | `F3` または `Enter` |
| 前の一致へ移動 | `Cmd + Shift + G` または `Shift + Enter` | `Shift + F3` または `Shift + Enter` |
| 選択範囲内のみ検索 | 検索バーの `Find in Selection` トグル（`Option + L` / `Alt + L`） | 同左 |
| 検索バーを閉じる | `Esc` | `Esc` |

検索バーの右側にある 3 つのトグル:

- **Aa** — 大文字小文字を区別
- **Ab|** — 単語単位の一致のみ（部分一致を除外）
- **`.*`** — 正規表現として解釈

正規表現モードでは置換側で `$1`、`$2` などのキャプチャ参照が使えます。

---

## ワークスペース検索の機能

サイドバーの検索ビュー（虫眼鏡アイコン）または `Cmd/Ctrl + Shift + F` で開きます。エディタ内検索にはない強力な機能が揃っています。

### include / exclude グロブ

検索バーの下にある `files to include` / `files to exclude` 欄でファイル範囲を絞ります。

| 例 | 意味 |
|----|------|
| `**/*.ts` | 全ディレクトリの `.ts` ファイル |
| `src/**` | `src` 配下のすべて |
| `!**/*.test.ts` | テストファイルを除外 |
| `app, lib` | カンマ区切りで複数指定 |

`files to exclude` の右にある歯車マークを切り替えると、`.gitignore` や設定 `files.exclude` を **無視するかどうか** を一時的に変更できます。

### 結果の操作

- 結果ツリーの行をクリック → 該当箇所をプレビュー表示
- 行の右に出る `×` で **そのマッチを除外**（一括置換から外せる）
- 上部の `Replace All` で残った全マッチを置換

### 検索履歴

検索バーで `↑` / `↓` を押すと過去の検索ワードを呼び出せます。複雑な正規表現を再利用するときに便利です。

---

## 高度な検索

| 機能 | 使い方 |
|------|--------|
| **シンボル検索** | コマンドパレットで `@`（現在ファイル）/ `#`（ワークスペース） |
| **複数行検索** | エディタ検索バーで `Shift + Enter` で改行を入力、または正規表現の `\n` |
| **検索結果をエディタで開く** | コマンド `Search: Open Search Editor`（結果を保存・編集できるバッファに） |

---

## ありがちなつまずき

- 「Replace All を押したら関係ない箇所まで変わった」 → `Aa` トグルで大文字小文字、`Ab|` で単語単位の一致を有効に。実行前にツリーで件数を確認するのが安全
- 「`node_modules` まで検索される」 → `files.exclude` / `search.exclude` 設定を確認。一時的なら検索バーの歯車で `.gitignore` 尊重をトグル
- 「正規表現が効かない」 → `.*` トグルがオンになっているか確認
- 「マルチルートワークスペースで一部フォルダだけ検索したい」 → `files to include` に `./folder-name/**` を指定
