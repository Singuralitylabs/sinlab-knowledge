# マルチカーソル

## 解説

**マルチカーソル** は、複数の位置に同時にカーソルを置いて、まったく同じ編集を一度に行う機能です。手動で繰り返していたタイピングや、Find & Replace では難しい「規則性のある一括編集」を一気に終わらせられます。

VS Code の生産性を大きく押し上げる機能のひとつで、ショートカット 3 つ（クリックで追加、次の一致を追加、全一致を選択）を覚えるだけで日常的な編集が一段速くなります。

---

## カーソルを追加する 3 つの方法

### 1. クリックで任意の位置に追加

| 操作 | macOS | Windows / Linux |
|------|-------|-----------------|
| 任意の位置にカーソル追加 | `Option + クリック` | `Alt + クリック` |
| 上下にカーソルを伸ばす | `Cmd + Option + ↑` / `↓` | `Ctrl + Alt + ↑` / `↓` |
| 直前のカーソル追加を取り消す | `Cmd + U` | `Ctrl + U` |
| マルチカーソル解除（単一に戻す） | `Esc` | `Esc` |

### 2. 同じ語を順に追加

選択語と同じ単語を 1 つずつ追加していきます。

| 操作 | macOS | Windows / Linux |
|------|-------|-----------------|
| 次の同一語を選択に追加 | `Cmd + D` | `Ctrl + D` |
| 直前の追加をスキップして次へ | `Cmd + K, Cmd + D` | `Ctrl + K, Ctrl + D` |

「変えたい箇所だけを順に確認しながら追加」したいときに最強です。

### 3. 全一致を一度に選択

| 操作 | macOS | Windows / Linux |
|------|-------|-----------------|
| 同じ語の全一致を一気に選択 | `Cmd + Shift + L` | `Ctrl + Shift + L` |
| 選択中の同一文字列の全一致を選択 | コマンド `Selection: Select All Occurrences of Find Match` | 同左 |

ファイル全体に同じ修正を入れるときに使います。一括 Find & Replace との違いは、**選択状態のまま続けて自由な編集ができる** こと（前後に文字を足す、削除する、括弧で囲むなど）。

---

## 矩形（ブロック）選択

矩形の範囲を選択し、その縦の各行に同時にカーソルを配置します。表形式のデータや連続行への一括編集で便利です。

| 操作 | macOS | Windows / Linux |
|------|-------|-----------------|
| 矩形選択（マウスドラッグ） | `Shift + Option + ドラッグ` | `Shift + Alt + ドラッグ` |
| 矩形選択（カーソル拡張） | `Shift + Option + Cmd + ↑/↓/←/→` | `Ctrl + Shift + Alt + ↑/↓/←/→` |

---

## 実用例

### 例 1：複数の `let` を `const` に一括変更

1. `let` を選択
2. `Cmd/Ctrl + Shift + L` で全一致を選択
3. `const` と打鍵 → 全行が同時に書き換わる

### 例 2：すべての行末にカンマを追加

1. 連続行の先頭に矩形選択でカーソルを配置（`Shift + Alt/Option + ↓`）
2. 各カーソルで `End` を押し行末へ
3. `,` を入力

### 例 3：似た単語のうち一部だけを置換

1. 単語を選択
2. `Cmd/Ctrl + D` で次の一致を追加
3. 関係ない一致が出たら `Cmd/Ctrl + K, Cmd/Ctrl + D` でスキップ
4. 必要な箇所だけ選択した状態で編集

---

## ありがちなつまずき

- 「`Cmd/Ctrl + D` を押しすぎて関係ない箇所まで選択した」 → `Cmd + U` / `Ctrl + U` で 1 段階ずつ取り消せる
- 「マルチカーソル状態から抜けられない」 → `Esc` で単一カーソルに戻る
- 「矩形選択が始まらない」 → macOS では `Option`、Windows/Linux では `Alt` を必ず併用。トラックパッドの 2 本指ジェスチャと衝突することがある
- 「`Cmd + Shift + L` で全行が選択された」 → 既存の選択範囲が空（カーソルだけ）の状態で押すと現在行の全選択になる挙動。先に語を選んでから押す
