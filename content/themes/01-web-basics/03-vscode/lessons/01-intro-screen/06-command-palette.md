# コマンドパレット

## 解説

**コマンドパレット** は、VS Code の **すべての操作にテキスト検索でアクセスできる** オーバーレイです。これを使いこなすかどうかが、初心者と中級者を分ける最大のポイントといっても過言ではありません。

「どこのボタンを押せば良いか分からない」と思ったら、まずコマンドパレットを開いて操作名で検索します。

![コマンドパレットを開いた状態（候補一覧の右側にショートカットキーが併記される）](/content-assets/01-web-basics/03-vscode/images/02-command-palette.png)

---

## 起動方法

| 操作 | macOS | Windows / Linux |
|------|-------|-----------------|
| コマンドパレットを開く | `Cmd + Shift + P` または `F1` | `Ctrl + Shift + P` または `F1` |
| ファイルクイックオープン | `Cmd + P` | `Ctrl + P` |

---

## プレフィックスでモード切替

入力欄の先頭に付ける記号で、検索対象のモードが切り替わります。

| プレフィックス | モード | 例 |
|----------------|-------|-----|
| なし | ファイルクイックオープン（`Cmd/Ctrl + P` 相当） | `auth.ts` |
| `>` | コマンド検索（`Cmd/Ctrl + Shift + P` 相当） | `>format document` |
| `@` | 現在ファイルのシンボル | `@handleSubmit` |
| `@:` | 現在ファイルのシンボル（カテゴリ付き） | `@:` でカテゴリごとに表示 |
| `#` | ワークスペース全体のシンボル | `#useAuth` |
| `:` | 行番号（行:列）ジャンプ | `:42` / `:42:5` |
| `?` | ヘルプ（使えるモード一覧を表示） | `?` |

入力中、表示される候補の右側に **ショートカットキーが併記** されます。これを見ながら自然と覚えていくのが最速です。

---

## よく使うコマンド例（`>` モード）

| 入力 | 機能 |
|------|------|
| `>format document` | ファイル全体をフォーマット |
| `>preferences: open user settings` | 設定 UI を開く |
| `>preferences: open user settings (json)` | settings.json を直接編集 |
| `>preferences: color theme` | カラーテーマを切替 |
| `>git: clone` | リポジトリをクローン |
| `>view: toggle word wrap` | 折り返し表示を切替 |
| `>terminal: select default profile` | 既定シェルを変更 |
| `>developer: reload window` | VS Code を再読み込み（拡張不調時に有効） |

すべて覚える必要はありません。「フォーマットしたい」「設定を変えたい」と思ったら、関連語を打って候補を眺めるだけで十分です。

---

## 履歴と再実行

- コマンドパレットを開くと、**直前に使ったコマンドが先頭に表示** されます
- そのまま `Enter` で再実行できるため、繰り返し使う操作（ビルド、テストなど）はキーバインドを覚える前にこれで十分なことが多い

---

## ありがちなつまずき

- 「`Cmd/Ctrl + P` でファイル名検索のはずなのにコマンドが出る」 → 入力欄の先頭が `>` になっていないか確認（前回 `Cmd/Ctrl + Shift + P` で開いた状態を引き継いでいる）
- 候補がまったく出ない → 拡張機能のロード待ち。`>developer: reload window` で再読み込み
- ショートカットを忘れた操作がある → コマンドパレットで操作名を打てば、候補にショートカットが併記されている
