# パネル

## 解説

**パネル** はエディタの下（または右）に表示される補助領域で、コーディング中に頻繁に参照する情報がタブ形式で並びます。既定では次の 4 つが表示されます。

![下部パネル：問題 / 出力 / デバッグコンソール / ターミナル のタブ列](/content-assets/01-web-basics/03-vscode/images/06-panel.png)

| タブ | 役割 |
|------|------|
| **問題（Problems）** | 言語サーバや Linter が検出したエラー / 警告の一覧 |
| **出力（Output）** | 各拡張機能や言語サーバのログ |
| **デバッグコンソール（Debug Console）** | デバッグ実行中に式の評価やログ出力を確認 |
| **ターミナル（Terminal）** | 統合シェル（bash / zsh / PowerShell など） |

**Ports**（ポート転送）タブは Remote-SSH / Dev Containers / WSL / Codespaces などのリモート接続中に自動で追加されます。**GitHub Pull Requests** や **Test Results** など、拡張機能の導入で追加されるタブもあります。

## 開閉と位置

| 操作 | macOS | Windows / Linux |
|------|-------|-----------------|
| パネル表示切替 | `Cmd + J` | `Ctrl + J` |
| ターミナルを開く | `` Ctrl + ` `` | `` Ctrl + ` `` |
| パネルを最大化 | コマンド `View: Toggle Maximized Panel` | 同左 |
| パネルの位置切替 | コマンド `View: Move Panel ...`（**Top** / **Bottom** / **Left** / **Right**） | 同左 |

パネルは下部だけでなく **上部・左・右に配置** することも可能です。横画面で広いモニターを使うときは右配置が見やすく、コードに集中したいときは Top / Hidden が有効です。

## 各タブの使いどころ

### 問題（Problems）

TypeScript の型エラーや ESLint の警告など、**ファイルを開かなくても** プロジェクト内のエラーを一望できます。クリックすれば該当箇所にジャンプ。フィルタで `Errors` のみ表示することも可能です。

### 出力（Output）

右上のドロップダウンで **どの拡張機能のログを見るか** を切り替えます。「動かない」「設定が効かない」と感じたら、まず該当拡張のログをここで確認するのが定石です。

### デバッグコンソール

`実行とデバッグ` でブレークポイントを置いて停止中、変数を覗いたり式を評価したりできます。`console.log` の出力もここに流れます。

### ターミナル

別ウィンドウのターミナルアプリと違い、**プロジェクトのルートが自動でカレントディレクトリ** になります。詳細は基本操作カテゴリの `統合ターミナル` 詳細を参照。

## ありがちなつまずき

- パネルが消えた → `Cmd/Ctrl + J` で開閉トグル
- パネルの位置がいつの間にか右になった → 同コマンドの `Move Panel To Bottom` で戻せる
- ターミナルが小さくなった → パネルの最大化（`View: Toggle Maximized Panel`）でフルサイズに
