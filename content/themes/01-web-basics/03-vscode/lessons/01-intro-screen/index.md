# VS Code のインストールと画面構成

## はじめに

### このレッスンのゴール

このレッスンでは、まず VS Code を OS にインストールする手順を確認したあと、起動した画面の構成を理解します。VS Code の画面は **5 つの大きな領域 + 1 つのオーバーレイ（コマンドパレット）** に分けて捉えると一気に整理できます。

すでに VS Code が入っている方はインストール節を読み飛ばして、画面構成から始めてください。

> **Tips**：本レッスンで紹介するキーボードショートカットは macOS と Windows / Linux の両方を併記しています。お使いの OS に合わせて読み替えてください。

---

## インストール

### ダウンロード

[VS Code 公式サイト](https://code.visualstudio.com/) にアクセスします。トップページに表示される **"Download for ..."** ボタンが、自動でアクセスしている OS に応じて切り替わります。

> **公式版とフォーク版**：VS Code には Microsoft 配布の公式版（ロゴが青）以外に、テレメトリを除いた OSS 版（**VSCodium**）や、AI 機能を中心に再パッケージしたフォーク（**Cursor**、**Windsurf** など）があります。本レッスンは公式版を前提とします。

### macOS

1. ダウンロードした `.zip` を展開
2. 中身の `Visual Studio Code.app` を **`/Applications/`** へドラッグ＆ドロップ
3. 初回起動時に「インターネットからダウンロードしたアプリ」の確認ダイアログが出たら "開く" を選択
4. Dock に常駐させたければ右クリック › "オプション" › "Dock に追加"

Apple Silicon（M1 / M2 / M3 など）と Intel で別バイナリが配布されていますが、公式サイトは自動判定して適切なものを配ります。手動で選びたい場合は **Universal** 版を使えば両対応です。

### Windows

1. ダウンロードした `VSCodeUserSetup-<version>.exe` を実行
2. ライセンスに同意 → インストール先を選ぶ（既定で OK）
3. **追加タスク** の画面で次の項目をチェックしておくと便利:
   - **`PATH` への追加**（`code` コマンドが使えるようになる）
   - **エクスプローラーのコンテキストメニューに "Code で開く" を追加**

User Installer（個人ユーザー）と System Installer（全ユーザー共通）の 2 種類があり、自分専用の PC なら User 版で十分です。

### `code` コマンドを PATH に通す（macOS）

ターミナルから `code .` のようにディレクトリを開けるようにします。

1. VS Code を起動
2. コマンドパレット（`Cmd + Shift + P`）を開く
3. **`Shell Command: Install 'code' command in PATH`** を実行

その後、ターミナルで:

```bash
code --version    # バージョンが表示されればOK
code .            # 現在のディレクトリを VS Code で開く
```

Windows でインストール時に「PATH への追加」をチェックしていれば、コマンドプロンプト / PowerShell から `code` が使えます。

### 日本語化（任意）

VS Code は標準では英語 UI です。日本語に切り替えたい場合は拡張機能 **`Japanese Language Pack for Visual Studio Code`**（パブリッシャ：MS-CEINTL）をインストールします。

1. アクティビティバーの拡張機能（`Cmd/Ctrl + Shift + X`）を開く
2. `Japanese Language Pack` で検索
3. インストール後、再起動を促す通知が出るので「Restart」

> **Tips**：開発時は公式ドキュメントやエラーメッセージとの一貫性のため英語のまま使う人も多いです。学習段階で日本語化し、慣れたら英語に戻す、という選び方もあります。

### インストール周りのつまずき

- 「`code` コマンドが見つからない」 → コマンドパレットで `Shell Command: Install 'code' command in PATH` を再度実行。シェルの再起動も忘れずに
- 「インストールしたが起動しない」（macOS） → Gatekeeper のブロックの可能性。"システム設定" › "プライバシーとセキュリティ" で許可
- 「自動アップデートを止めたい」 → 設定 `update.mode` を `manual` または `none` に

## 画面全体の俯瞰

VS Code のメインウィンドウは、おおまかに以下の領域で構成されています。

![VS Code のメインウィンドウ全景：アクティビティバー / サイドバー / エディタ領域 / パネル / ステータスバー](/content-assets/01-web-basics/03-vscode/images/01-vscode-window.png)

加えて、画面のどこからでも `Cmd + Shift + P` / `Ctrl + Shift + P` で呼び出せる **コマンドパレット** がオーバーレイで表示されます。

| 領域 | 役割 | 主な用途 |
|------|------|---------|
| アクティビティバー | 左端のアイコン列 | サイドバーで開く機能の切り替え |
| サイドバー | 機能ごとのリスト/ツリー | ファイル・検索結果・Git変更などを表示 |
| エディタ領域 | コード編集の中心 | ファイルを開いて編集、複数タブ・分割表示 |
| パネル | 下部の補助領域 | ターミナル / 問題 / 出力 / デバッグコンソール |
| ステータスバー | 最下部の細い帯 | Gitブランチ、エラー数、行列、言語モード等 |
| コマンドパレット | オーバーレイ | すべての機能をテキスト検索で実行 |

---

## 各領域の概要

### 1. アクティビティバー（左端のアイコン列）

`エクスプローラー` `検索` `ソース管理` `実行とデバッグ` `拡張機能` などのメイン機能を切り替えるためのアイコンが縦に並んでいます。下部にはアカウントと管理（歯車）アイコンがあります。

::detail{slug="activity-bar"}

### 2. サイドバー

アクティビティバーで選んだ機能の中身が表示される領域です。エクスプローラーであればファイルツリー、検索であれば検索結果、ソース管理であれば変更ファイル一覧、といった具合に内容が切り替わります。プライマリサイドバーとセカンダリサイドバーの 2 つに分けて配置することもできます。

::detail{slug="side-bar"}

### 3. エディタ領域

実際にコードを編集するメイン領域です。複数のファイルを **タブ** で並べて切り替えたり、**エディタを分割** して 2 つ以上のファイルを並べて見たりできます。タブがイタリック（斜体）で表示されているときはプレビュー状態で、そのまま別ファイルを開くと現在のタブが置き換わります。

::detail{slug="editor-area"}

### 4. パネル（下部）

エディタの下に表示される補助領域です。`問題` `出力` `デバッグコンソール` `ターミナル` の 4 つのタブが既定で並びます。位置は下・右・最大化を切り替えられ、用途に応じて使い分けます。

::detail{slug="panel"}

### 5. ステータスバー（最下部）

VS Code の状態を一目で確認できる細い帯です。左側には Git ブランチ名やエラー / 警告の件数、右側にはカーソルの行列、エンコーディング、改行コード、言語モードなどが表示されます。多くの項目はクリックでメニューが開き、その場で切り替えできます。

::detail{slug="status-bar"}

### 6. コマンドパレット（オーバーレイ）

`Cmd + Shift + P` / `Ctrl + Shift + P` で呼び出せる、VS Code の **すべての操作にテキスト検索でアクセスできる** 機能です。先頭に付ける記号によってモードが切り替わります。

| プレフィックス | モード | 例 |
|----------------|-------|---|
| （なし） | ファイル名検索（`Cmd/Ctrl + P` と同じ） | `auth.ts` |
| `>` | コマンド検索 | `>format document` |
| `@` | 現在ファイルのシンボル | `@functionName` |
| `#` | ワークスペース全体のシンボル | `#functionName` |
| `:` | 行番号（行:列）ジャンプ | `:42` / `:42:5` |

`Cmd + Shift + P` / `Ctrl + Shift + P` で開くと自動的に `>` が付与され、`Cmd + P` / `Ctrl + P` で開くと無印で開きます。同じ UI なので、開いた後に先頭の文字を打ち変えれば自由にモードを切り替えられます。

ボタンの位置を覚えるよりも、**コマンドパレットからキーワードで操作を呼び出すほうが早い**ことが多々あります。

::detail{slug="command-palette"}

## まとめ

- VS Code の画面は **アクティビティバー / サイドバー / エディタ領域 / パネル / ステータスバー** の 5 領域 + コマンドパレット
- 各領域の役割を押さえれば、初めて見るアイコンでも「どこの何を操作するボタンか」が見当をつけやすい
- 詳細は各 detail ページで個別に解説しています
