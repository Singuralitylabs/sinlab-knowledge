# ステータスバー

## 解説

**ステータスバー** は VS Code ウィンドウ最下部の細い帯です。一見地味ですが、ここを読むと「いま VS Code がどんな状態か」が一目で把握でき、ほとんどの項目はクリックでメニューが開いて即座に変更できます。

![ステータスバー全体（左：Git ブランチ / エラー件数、右：行列 / エンコーディング / 改行コード / 言語モード）](/content-assets/01-web-basics/03-vscode/images/07-status-bar.png)

---

## 左側に表示される情報

| 項目 | 内容 | クリック時の挙動 |
|------|------|-------------------|
| **リモート接続インジケータ** | SSH / Dev Container / WSL 接続中の表示（緑または青） | 接続を切替 / 切断 |
| **Git ブランチ** | 現在のブランチ名と同期マーク | ブランチ一覧を表示して切替 |
| **エラー / 警告件数** | `⊗ 2  ⚠ 5` のような数値 | パネルの「問題」を開く |
| **バックグラウンドタスク** | スピナー付きのテキスト（インストール中など） | タスクの詳細を表示 |

---

## 右側に表示される情報

| 項目 | 内容 | クリック時の挙動 |
|------|------|-------------------|
| **行: 列** | カーソルの位置（例: `Ln 42, Col 12`） | 行ジャンプダイアログを表示 |
| **インデント** | `Spaces: 2` または `Tab Size: 4` | スペース/タブの切替・サイズ変更 |
| **エンコーディング** | `UTF-8` など | 別エンコーディングで再オープン / 保存 |
| **改行コード** | `LF` / `CRLF` | 改行コードを変更 |
| **言語モード** | `TypeScript` `Markdown` など | 言語モードを変更 |
| **通知ベル** | 通知の有無 | 通知一覧を表示 |

> **拡張機能による追加表示**：Prettier / Biome / ESLint のフォーマッタ・Linter、GitLens の作者表示、Live Share のセッション情報、Copilot の利用状況などは標準ではなく、**それぞれの拡張機能がステータスバーに項目を追加** したものです。

---

## カスタマイズ

- ステータスバーの **項目自体を非表示** にしたいときは、コマンド `View: Toggle Status Bar Visibility` でバー全体を、または右クリックで個別項目を切替
- 設定 `workbench.statusBar.visible` を `true` / `false` で切り替えても同じ制御ができる

---

## ありがちなつまずき

- 「保存したのに改行コードが Windows 形式になっている」 → 右側の `LF` / `CRLF` 表示をクリックして変更
- 「文字化けする」 → エンコーディング表示をクリックして `Reopen with Encoding` で UTF-8 などに切替
- ステータスバーが消えた → コマンド `View: Toggle Status Bar Visibility`
