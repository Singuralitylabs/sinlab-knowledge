# サイドバー

## 解説

**サイドバー** は、アクティビティバーで選んだ機能の中身を表示する縦長のパネルです。エクスプローラーを選べばファイルツリー、検索を選べば検索結果、というように内容が切り替わります。

VS Code 1.64 以降、サイドバーは **プライマリ** と **セカンダリ** の 2 つを同時に出せるようになりました。たとえばプライマリにエクスプローラー、セカンダリにアウトラインを置く、といった使い分けが可能です。

## エクスプローラーの構成

エクスプローラー（書類アイコン）を開くと、サイドバーの中はさらに複数のセクションに分かれています。

| セクション | 内容 |
|------------|------|
| **OPEN EDITORS** | 現在開いているタブの一覧 |
| **<フォルダ名>** | ワークスペースのファイルツリー |
| **OUTLINE** | 現在開いているファイルのシンボル（関数・クラス・見出しなど） |
| **TIMELINE** | ファイルのコミット履歴・ローカル変更履歴 |

各セクションのヘッダをクリックすると折りたためます。`...` メニューから個別にセクションを表示 / 非表示にできます。

---

## サイズ調整と位置変更

| 操作 | macOS | Windows / Linux |
|------|-------|-----------------|
| プライマリサイドバーの表示切替 | `Cmd + B` | `Ctrl + B` |
| セカンダリサイドバーの表示切替 | `Cmd + Alt + B` | `Ctrl + Alt + B` |

| 操作 | やり方 |
|------|--------|
| 幅を変更 | サイドバーとエディタの境界をドラッグ |
| 左右の入れ替え | コマンドパレットで `View: Move Primary Side Bar Right` / `Left`（または `View: Toggle Primary Side Bar Position`） |

---

## プライマリ vs セカンダリ

| | プライマリサイドバー | セカンダリサイドバー |
|---|---|---|
| 既定の位置 | 左 | 右 |
| 用途 | エクスプローラー / 検索など中心機能 | 近年は AI アシスタントの常駐先として標準化が進む（VS Code は GitHub Copilot Chat、Cursor は AI エージェントの入力欄が既定で表示される）。アウトライン / ソース管理など他のビューを並列で置くこともできる |
| 移動 | パネルやセクションをドラッグして移動 | 同左 |

ビューをドラッグするだけで、プライマリ ⇄ セカンダリ ⇄ パネル間を自由に行き来できます。

---

## ありがちなつまずき

- 「ファイルツリーが消えた」 → `Cmd/Ctrl + B` でサイドバー表示。それでも出ない場合はアクティビティバーでエクスプローラーを選び直す
- アウトラインが空 → 言語サーバが未起動 / 対応言語の拡張未インストールの可能性
- ファイル名のすぐ右に数字バッジ → エラーや Git の変更件数
