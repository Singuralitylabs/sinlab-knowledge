# エディタ領域

## 解説

**エディタ領域** は VS Code の中心部、実際にコードを編集するメインスペースです。タブ・グループ（分割）・ミニマップ・ブレッドクラムなど、見えているものすべてに役割があります。

---

## タブの種類

| タブの状態 | 見た目 | 意味 |
|------------|--------|------|
| プレビュー | タイトルが **イタリック** | 一時的に開いているだけ。別ファイルを開くとこのタブが置き換わる |
| 通常 | 普通の表示 | 明示的に保持されているタブ |
| ピン留め | 鋲アイコン | 常に左端に固定。タブを大量に開いても流れない |
| 未保存 | ファイル名横に `●` | 保存されていない変更あり |

**プレビュータブ** はファイルを **シングルクリック** で開いた時に発生します。タブをダブルクリックするか、ファイルツリーでファイルをダブルクリックすると通常タブになります。

| 操作 | macOS | Windows / Linux |
|------|-------|-----------------|
| タブを閉じる | `Cmd + W` | `Ctrl + W` |
| タブをピン留め | コマンド `View: Pin Editor` | 同左 |
| 直前に閉じたタブを再度開く | `Cmd + Shift + T` | `Ctrl + Shift + T` |
| タブを切替（履歴順） | `Ctrl + Tab`（macOS でも `Cmd` ではなく `Ctrl`） | `Ctrl + Tab` |

---

## エディタの分割（グループ）

複数ファイルを並べて見るための機能です。

| 操作 | macOS | Windows / Linux |
|------|-------|-----------------|
| エディタを右に分割 | `Cmd + \` | `Ctrl + \` |
| 次のグループへフォーカス移動 | `Cmd + K, Cmd + →` | `Ctrl + K, Ctrl + →` |
| グループのレイアウトを変更 | コマンド `View: Editor Layout: ...` | 同左 |

水平分割（`Cmd/Ctrl + K, Cmd/Ctrl + \`）や、縦/横/グリッド/2x2 など、用途に応じてレイアウトを切り替えられます。

---

## エディタの装飾要素

| 要素 | 説明 | 切替 |
|------|------|------|
| **行番号** | 左端の数字 | 設定 `editor.lineNumbers`（off / on / relative / interval） |
| **ミニマップ** | 右端の縮小ビュー | 設定 `editor.minimap.enabled` |
| **ブレッドクラム** | エディタ上部のパス＋シンボル列 | コマンド `View: Toggle Breadcrumbs` |
| **スティッキースクロール** | スクロール中、現在の関数 / クラスなど親スコープの先頭行を上部に固定表示 | 設定 `editor.stickyScroll.enabled`（既定で有効） |
| **ガター** | 行番号の左の余白 | デバッグのブレークポイントや Git 変更マーカーが表示される |
| **折り返し** | 長い行を画面幅で折り返す | `Alt + Z` / `Option + Z` |
| **インデントガイド** | インデントの縦の線 | 設定 `editor.guides.indentation` |

---

## スクロールと折りたたみ

- マウスのホイール / トラックパッドでスクロール
- 行番号をクリックすると行全体を選択
- インデントの矢印（▶/▼）で **コードの折りたたみ / 展開**

| 操作 | macOS | Windows / Linux |
|------|-------|-----------------|
| 折りたたみ | `Option + Cmd + [` | `Ctrl + Shift + [` |
| 展開 | `Option + Cmd + ]` | `Ctrl + Shift + ]` |
| すべて折りたたみ | `Cmd + K, Cmd + 0` | `Ctrl + K, Ctrl + 0` |
| すべて展開 | `Cmd + K, Cmd + J` | `Ctrl + K, Ctrl + J` |

---

## ありがちなつまずき

- タブが次々と上書きされる → プレビュータブの仕様。タブをダブルクリックして通常タブ化、またはピン留め
- 「右に分割しすぎてレイアウトが崩れた」 → コマンド `View: Editor Layout: Single` で 1 つに戻せる
- 折り返しが効かない → `Alt/Option + Z` でトグル
