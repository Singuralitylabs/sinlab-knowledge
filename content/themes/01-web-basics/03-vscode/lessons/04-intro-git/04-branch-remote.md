# ブランチ操作とリモート同期

## 解説

ブランチの切替・作成・リモートへの同期は、ステータスバー左端と Source Control（ソース管理）パネルの `...` メニューを使い分けます。日常作業の 8 割はステータスバーから完結します。

---

## ステータスバーのブランチ表示

VS Code ウィンドウ最下部の **左端** に、現在のブランチ名と同期マークが表示されます。

```
 main  ↓ 0  ↑ 2
```

| 要素 | 意味 |
|------|------|
|  | Git リポジトリ内であることを示すアイコン |
| `main` | 現在のブランチ名 |
| ↓ N | リモートにあるがローカルに取り込んでいないコミット数 |
| ↑ N | ローカルにあるがリモートにプッシュしていないコミット数 |

## ブランチを切り替える / 作る

ステータスバーの **ブランチ名をクリック** すると、ブランチ操作メニューがコマンドパレット風に開きます。

| メニュー項目 | 動作 |
|--------------|------|
| 既存ブランチを選択 | そのブランチへ checkout |
| **`Create new branch...`**（新しいブランチを作成...） | 現在の HEAD から新規ブランチを作成 |
| **`Create new branch from...`**（次から新しいブランチを作成...） | 任意の起点（別ブランチや特定コミット）から新規作成 |
| **`Checkout detached...`**（切り離された状態でチェックアウト...） | 特定コミットを detached HEAD で開く |

ブランチ名の絞り込み検索もできるので、ブランチが多いリポジトリでも素早く目的のブランチへ移動できます。

### コマンドパレットからのブランチ操作

`Cmd/Ctrl + Shift + P` で `Git: Branch` と打つと、より細かい操作が一覧されます。

| コマンド | 動作 |
|---------|------|
| `Git: Create Branch`（Git: ブランチの作成） | 新規ブランチを作る |
| `Git: Create Branch From...`（Git: 次からブランチを作成...） | 起点を指定して作る |
| `Git: Rename Branch`（Git: ブランチ名の変更） | 現在のブランチ名を変更 |
| `Git: Delete Branch`（Git: ブランチの削除） | ローカルブランチを削除 |
| `Git: Checkout to...`（Git: チェックアウト先...） | ブランチ / タグ / コミットへ checkout |
| `Git: Publish Branch`（Git: ブランチの発行） | ローカルだけで作ったブランチをリモートに登録 |

## リモートとの同期

### Sync Changes ボタン

コミット後、Source Control パネルの上部ボタンが **`Sync Changes`**（変更の同期）に変わります。これを押すと **`git pull` → `git push`** が一括で実行されます。

ステータスバーの `↓ N ↑ N` 表示部分をクリックしても同じ動作です。

### 個別に Push / Pull / Fetch

Source Control パネル右上の `...` メニューから個別操作を選べます。

| 項目 | コマンド相当 |
|------|--------------|
| **Pull**（プル） | `git pull` |
| **Push**（プッシュ） | `git push` |
| **Fetch**（フェッチ） | `git fetch`（マージしない） |
| **Pull (Rebase)**（プル (リベース)） | `git pull --rebase` |
| **Push to...**（プッシュ先...） | リモート / ブランチを明示してプッシュ |
| **Sync**（同期） | Pull + Push |

「リモートに変更がないか確認だけしたい」場合は **Fetch** を使うと、現在の作業を中断せずに ↑↓ カウントだけ更新できます。

### 初回プッシュ（Publish Branch）

ローカルだけで新規作成したブランチをリモートに送るには **`Publish Branch`**（ブランチの発行）を使います。Source Control パネルにそのままボタンが現れることもあれば、`Git: Publish Branch` をコマンドパレットから呼ぶこともできます。CLI の `git push -u origin <branch>` 相当です。

---

## クローン

新しいリポジトリを取得するには:

1. コマンドパレット → **`Git: Clone`**（Git: クローン）
2. リポジトリ URL を入力
3. クローン先のフォルダを選択
4. クローン完了の通知から「Open」（開く）または「Open in New Window」（新しいウィンドウで開く）

GitHub と連携している場合、URL ではなくアカウント内のリポジトリを一覧から選ぶ UI も表示されます。

## ありがちなつまずき

- 「Push したのにリモートに反映されない」 → 認証エラーの通知が出ていないか確認。GitHub では HTTPS の場合は PAT、SSH なら鍵設定が必要
- 「↑↓ カウントが古い」 → リモートを Fetch していないだけ。ステータスバーの ↻（リフレッシュ）か `...` › `Fetch`
- 「Publish Branch ボタンが出ない」 → リモート（`origin`）が登録されていない可能性。`...` › `Add Remote...`（リモートの追加...）で登録
- 「pull で巻き戻された」 → `Pull (Rebase)` を使うか、コミット前に `Fetch` で差分を確認してから取り込む
