# VS Code のキーボードショートカット

## はじめに

### このレッスンのゴール

VS Code は **マウスを使わず、ほぼすべての操作をキーボードだけで行える** ように設計されています。最初はショートカットを覚えるのが大変に感じますが、用途別に少しずつ身につけていけば、コーディング速度は確実に上がります。

このレッスンでは、覚える順番の指針と、用途別の代表的なショートカットを紹介します。詳細は各 detail ページにまとめています。

> **OS 表記について**：本レッスンでは macOS（Cmd / Option キー）と Windows / Linux（Ctrl / Alt キー）を併記します。

---

## 覚える順番の指針

ショートカットを「全部いっぺんに覚える」のは現実的ではありません。次の順序で段階的に拡張していくのがおすすめです。

```
1. コマンドパレット（Cmd/Ctrl + Shift + P）
   ↓ あらゆる操作はここから検索できる、という安心感
2. ナビゲーション（ファイル間・シンボル間ジャンプ）
   ↓ 目的のコードに素早くたどり着ける
3. 編集（行操作・コメント・フォーマット）
   ↓ 一気に書き換えられる
4. 検索（エディタ内・ワークスペース全体）
   ↓ リファクタリングが速くなる
5. マルチカーソル
   ↓ 同じ編集を一度に
6. ウィンドウ操作（分割・パネル開閉・ZenMode）
   ↓ 表示を整えて集中
```

> **Tips**：覚えていないショートカットは **コマンドパレット** で機能名を検索すれば、その横にショートカットが表示されます。これを繰り返すうちに自然と手が覚えていきます。

## 万能のひとつ：コマンドパレット

| 操作 | macOS | Windows / Linux |
|------|-------|-----------------|
| コマンドパレットを開く | `Cmd + Shift + P` | `Ctrl + Shift + P` |
| ファイルクイックオープン | `Cmd + P` | `Ctrl + P` |
| 設定を開く | `Cmd + ,` | `Ctrl + ,` |
| キーバインド設定を開く | `Cmd + K, Cmd + S` | `Ctrl + K, Ctrl + S` |

**ボタンの位置を覚えるよりコマンドパレットを使うほうが速いことが多々あります。** これだけは早めに覚えてしまうのが得策です。

## 用途別レッスン

### 1. ナビゲーション

ファイル間ジャンプ、シンボルジャンプ、定義へ移動 / 戻る、エディタタブ切替など、「目的のコードにたどり着く」ためのショートカット。

::detail{slug="navigation"}

### 2. 編集

行のコピー / 移動 / 削除、行コメントトグル、ブロックコメント、フォーマット、インデント変更、Emmet 展開など、「コードを書き換える」ためのショートカット。

::detail{slug="editing"}

### 3. 検索

エディタ内検索、ワークスペース全体検索、置換、正規表現切替、検索履歴ナビゲーションなど。

::detail{slug="search"}

### 4. マルチカーソル

複数箇所を同時に編集するためのキー操作。コーディング速度に直結する強力な機能です。

::detail{slug="multi-cursor"}

### 5. ウィンドウ操作

エディタ分割、サイドバー / パネルの開閉、ズーム、ZenMode、エディタタブ切替など。

::detail{slug="window"}

## まとめ

- ショートカットは **コマンドパレット → ナビゲーション → 編集 → 検索 → マルチカーソル → ウィンドウ** の順で増やしていく
- 覚えていない操作はコマンドパレットで検索すれば、その横にショートカットが表示される
- カスタマイズはキーバインド設定（`Cmd/Ctrl + K, Cmd/Ctrl + S`）で。詳しくは `設定とカスタマイズ` カテゴリの `キーバインド` 詳細を参照
