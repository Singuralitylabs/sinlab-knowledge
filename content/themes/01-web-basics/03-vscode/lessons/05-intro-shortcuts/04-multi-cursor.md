# マルチカーソル

## 解説

マルチカーソルは「同じ編集を複数箇所に一度で適用する」機能で、コーディング速度に直結します。**最初の 3 つのキー**（`Option/Alt + クリック`、`Cmd/Ctrl + D`、`Cmd/Ctrl + Shift + L`）だけ押さえれば、日常作業の大半をカバーできます。

機能の詳しい使い方や実用例は `基本操作` カテゴリの `マルチカーソル` 詳細を参照してください。ここでは **キー操作のみ** を反復で覚えるためのリファレンスとして整理します。

---

## カーソルを増やす

| 操作 | macOS | Windows / Linux |
|------|-------|-----------------|
| 任意の位置にカーソルを追加 | `Option + クリック` | `Alt + クリック` |
| 1 行上 / 下にカーソルを追加 | `Cmd + Option + ↑` / `↓` | `Ctrl + Alt + ↑` / `↓` |
| 次の同一語にカーソルを追加 | `Cmd + D` | `Ctrl + D` |
| 直前の追加をスキップして次へ | `Cmd + K, Cmd + D` | `Ctrl + K, Ctrl + D` |
| 同じ語の全一致を一度に選択 | `Cmd + Shift + L` | `Ctrl + Shift + L` |
| 選択中の文字列の全一致を選択 | `Cmd + F2` | `Ctrl + F2` |

---

## 矩形（ブロック）選択

| 操作 | macOS | Windows / Linux |
|------|-------|-----------------|
| マウスドラッグで矩形選択 | `Shift + Option + ドラッグ` | `Shift + Alt + ドラッグ` |
| キーボードで矩形選択を拡張 | `Shift + Option + Cmd + ↑/↓/←/→` | `Ctrl + Shift + Alt + ↑/↓/←/→` |

---

## マルチカーソルを解除する

| 操作 | macOS | Windows / Linux |
|------|-------|-----------------|
| 直前のカーソル追加を取り消す | `Cmd + U` | `Ctrl + U` |
| 単一カーソルに戻す | `Esc` | `Esc` |

`Cmd + D` / `Ctrl + D` を押しすぎて関係ない箇所まで選んでしまったときも、`Cmd + U` / `Ctrl + U` で 1 段階ずつ戻せます。

---

## ありがちなつまずき

- 「矩形選択が始まらない」 → macOS では `Option`、Windows/Linux では `Alt` を必ず併用。トラックパッドの 2 本指ジェスチャと衝突することがある
- 「`Cmd/Ctrl + Shift + L` で行全体が選択された」 → 既存の選択範囲が空（カーソルだけ）の状態で押すと現在行の全選択になる挙動。先に語を選んでから押す
- 「マルチカーソルから抜けられない」 → `Esc` で単一カーソルに戻る
