# ナビゲーション

## 解説

「目的のコードに素早くたどり着く」ためのショートカット集です。**マウスでファイルツリーをたどる時間が一番もったいない** ので、まずここを身につけると体感が変わります。

---

## ファイル間ジャンプ

| 操作 | macOS | Windows / Linux |
|------|-------|-----------------|
| ファイルクイックオープン | `Cmd + P` | `Ctrl + P` |
| 直近のファイル一覧（クイックオープンを開いた直後） | `Cmd + P` | `Ctrl + P` |
| 直前のエディタへ戻る | `Ctrl + Tab` | `Ctrl + Tab` |
| 隣のタブへ移動 | `Cmd + Option + ←` / `→` | `Ctrl + PageUp` / `PageDown` |
| 直前 / 直後のカーソル位置へ移動（履歴） | `Ctrl + -` / `Ctrl + Shift + -`（macOS。`Cmd` ではなく `Ctrl`） | `Alt + ←` / `Alt + →` |

`Ctrl + Tab` は押しっぱなしで「最近開いたエディタ」がオーバーレイ表示され、押すたびに履歴を遡れます。

---

## 同じファイル内のジャンプ

| 操作 | macOS | Windows / Linux |
|------|-------|-----------------|
| 行ジャンプ | `Ctrl + G` | `Ctrl + G` |
| 関数 / クラスなどシンボルへジャンプ | `Cmd + Shift + O` | `Ctrl + Shift + O` |
| シンボルをカテゴリ別表示 | `Cmd + Shift + O` の後に `:` | 同左 |
| 一致するブラケットへ移動 | `Cmd + Shift + \` | `Ctrl + Shift + \` |

`Cmd/Ctrl + Shift + O` の後で `:` を打つと「メソッド」「変数」のようにカテゴリでまとまり、長いファイルでも目当てのシンボルを素早く特定できます。

---

## ワークスペース全体のシンボル

| 操作 | macOS | Windows / Linux |
|------|-------|-----------------|
| ワークスペース内のシンボル検索 | `Cmd + T` | `Ctrl + T` |

クラス名や関数名を覚えていれば、ファイル名を知らなくても直接ジャンプできます。

---

## 定義へ移動・戻る

| 操作 | macOS | Windows / Linux |
|------|-------|-----------------|
| 定義へ移動 | `F12` または `Cmd + クリック` | `F12` または `Ctrl + クリック` |
| 定義を覗き見（ピーク） | `Option + F12` | `Alt + F12` |
| 参照を表示（呼び出し元一覧） | `Shift + F12` | `Shift + F12` |
| 実装へ移動（インターフェイス → 実装） | `Cmd + F12` | `Ctrl + F12` |
| ジャンプ前の位置へ戻る | `Ctrl + -` | `Alt + ←` |

---

## ブレッドクラムから探す

| 操作 | macOS | Windows / Linux |
|------|-------|-----------------|
| ブレッドクラムにフォーカス | `Cmd + Shift + .` | `Ctrl + Shift + .` |
| ブレッドクラムでシンボル選択 | フォーカス後 `↑` `↓` `←` `→` | 同左 |

長いネスト構造のファイルで、上の階層へさっと戻るのに便利です。

---

## ありがちなつまずき

- 「`F12` で定義に飛ばない」 → 言語サーバ（Language Server）が動いていないか、未インストールの可能性。「問題」パネルや拡張機能を確認
- 「直前位置へ戻れない」 → macOS は `Ctrl + -`（マイナスキー）。`Cmd` ではないので注意。前進は `Ctrl + Shift + -`
- 「`Cmd/Ctrl + P` に履歴が出てこない」 → 設定 `workbench.editor.enablePreview` の影響。プレビュータブで開いただけのファイルは履歴に残らないことがある
