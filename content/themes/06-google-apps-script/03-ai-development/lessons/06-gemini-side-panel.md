# エディタ内蔵 Gemini サイドパネルとの比較と使い分け

2026 年夏、Google は Google Apps Script のオンラインエディタ内に **Gemini サイドパネル（Gemini in the Apps Script IDE）** のベータ提供（Gemini Beta）を開始しました。これにより、外部のチャットツールを開くことなく、ブラウザのエディタ上で直接生成 AI の支援を受けられるようになりました。

本講座では主に「clasp × Claude Code」によるローカル環境での開発を推奨していますが、Gemini サイドパネルにもブラウザ完結ならではの大きな利点があります。

本ページでは、Gemini サイドパネルの機能、利用に必要なライセンス要件、得意な領域と不得意な領域、そして Claude Code との明確な使い分けの基準を整理します。

## Gemini サイドパネルとは

Gemini サイドパネルは、Apps Script エディタの右側に統合された公式の AI アシスタントです。エディタ右上の Gemini アイコン（✨）をクリックすることで展開されます。

```text
+-------------------------------------------------------------+-------------------+
|  [プロジェクト名]   [関数選択: myFunction v] [実行] [デバッグ]   |  ✨ Gemini        |
+--------------+----------------------------------------------+-------------------+
| [ファイル]   | function calculateTax(price) {               |  コードを解説して   |
|  コード.gs    |   return price * 0.1;                        |  この関数に消費税率 |
|              | }                                            |  10% のバリデー   |
|              |                                              |  ションを追加して  |
|              |                                              |                   |
|              |                                              |  [差分プレビュー]   |
+--------------+----------------------------------------------+-------------------+
| [実行ログ]                                                   | [メッセージ入力...] |
+-------------------------------------------------------------+-------------------+
```

### 主な機能

- **アクティブファイルの自動把握**: 現在エディタで開いているコードを自動的にコンテキストとして認識。
- **コード生成とインライン差分レビュー**: 生成されたコードはエディタ内でインライン diff として確認でき、確認後にワンクリックで保存・マージ可能。
- **実行ログからのワンクリック原因解析**: 実行エラーが発生した際、ログ画面のエラーから直接 Gemini に「なぜ失敗したのか」を問い合わせ可能。
- **自然言語による関数作成**: 「スプレッドシートの最終行を取得して Slack に送る関数を作って」といった指示から雛形を出力。

## 利用要件とライセンス（2026 年時点）

Gemini サイドパネルを利用するには、Google アカウントの種別に応じて以下のライセンス要件を満たす必要があります。

### 1. Google Workspace 組織アカウントの場合

以下のいずれかのライセンスが付与されており、かつドメイン管理者によって Google 管理コンソール上で Generative AI / Gemini Beta 機能が有効化されている必要があります。

- Google Workspace Business Standard
- Google Workspace Business Plus
- Google Workspace Enterprise Standard
- Google Workspace Enterprise Plus
- Google AI Pro for Education
- Workspace Gemini Add-on（Gemini Business / Gemini Enterprise アドオン）

### 2. 個人の Google アカウント（コンシューマー）の場合

- Google AI Pro または Google AI Ultra サブスクリプションに加入していること。

> [!NOTE]
> 現在の仕様として、**Google アカウントの言語設定が「英語（English）」に設定されていること**が推奨・要件となっている場合があります。また、同一ブラウザセッション内で複数の Google アカウントに同時ログインしているとサイドパネルが読み込まれないことがあるため、プロファイルを分けるかシークレットウィンドウでの利用が推奨されます。

## 得意なこと・不得意なこと

Gemini サイドパネルは非常に便利ですが、設計思想として「エディタの補助」に特化しているため、明確な限界があります。

### 得意なこと（強み）

1. **環境構築がゼロ**: Node.js や clasp、Git のインストールが不要。ブラウザを開くだけで即座に使える。
2. **単発の関数作成・リファクタリング**: 30〜50 行程度の関数を「ちょっと書いてもらう」「ログのエラーを解説してもらう」作業には最適。
3. **エディタとの密結合**: コードの挿入や置換がボタン 1 つで行え、コピペの手間が最小限。

### 不得意なこと（弱み・制約）

1. **プロジェクト全体の把握（複数ファイル）が苦手**:
   基本的に「現在開いているアクティブファイル」を中心に動作するため、10 個以上のファイルに分割された大規模プロジェクトの全体設計や整合性を保つのは困難。
2. **Git 管理やレビューフローが存在しない**:
   変更履歴はエディタの一時的な履歴に頼るため、ブランチを切って PR を作成したり、過去のコミットに安全にロールバックしたりできない。
3. **外部ツール・外部リソースとの連携ができない**:
   MCP のようにローカルのスクリプトを実行したり、GitHub と連携したりすることはできない。また、シート内の実データや外部 API に直接アクセスして検証することもできない。

## 使い分けの基準（マトリクス）

どのような場面でどちらを選択すべきか、以下の基準を参考にしてください。

| 観点 | Gemini サイドパネル | clasp × Claude Code |
| --- | --- | --- |
| **作業規模** | 1 ファイル、数十行〜100行程度の修正 | 複数ファイル、数百行〜数千行の大規模開発 |
| **開発環境** | ブラウザのみ（PC・タブレット） | ローカルマシン（VS Code, ターミナル） |
| **バージョン管理** | 不要（個人利用・使い捨て） | **必須（Git, GitHub, PR によるレビュー）** |
| **テスト・自動化** | ブラウザ上で手動実行 | **純粋関数の単体テストや CI による自動テスト** |
| **外部エコシステム** | なし（Google Apps Script 単体） | npm、TypeScript、Rollup バンドラ、MCP 連携 |
| **おすすめ対象** | 初心者、非エンジニア、即席の自動化 | **エンジニア、継続運用する業務システム** |

### 実践的な共存スタイル

両者は二者択一ではありません。

- **新規の大型機能や本格的な業務システム**:
  `clasp` でリポジトリを作成し、`Claude Code` でテストコードを含めて一気に構築する。
- **本番稼働中の軽微な文言修正や緊急デバッグ**:
  ブラウザでエディタを開き、`Gemini サイドパネル` でサッと原因を聞いて 1 行直す。

このように、それぞれの強みを理解して使い分けるのが最も効率的です。

## まとめ

- **Gemini サイドパネル**: エディタ内蔵の AI 支援機能（Gemini Beta）。環境構築不要で手軽にコード生成やエラー解説ができる。
- **ライセンス要件**: Workspace Business Standard 以上、または Google AI Pro などの有償ライセンスが必要。
- **限界**: 複数ファイル横断の設計、Git バージョン管理、自動テスト・外部連携はサポート外。
- **使い分け**: ちょっとした即席の修正は Gemini サイドパネル、本格的なチーム開発や保守性の高い業務アプリは clasp × Claude Code が最適。
